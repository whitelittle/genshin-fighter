## 实际观察

### 隆：特效服从身体动作

21.30秒仍是站姿；21.42秒明显下沉，随后双手在身体一侧聚能；21.78秒向前推出，21.90–22.02秒弹体离开手部；22.14秒对手处出现明亮命中光。手边发射光、飞行弹体、命中光是不同位置和阶段，不是同一团光一直跟角色移动。推进时腿形成稳定支撑，躯干也有前后变化。

对本项目的设计推论：那维莱特需要聚水姿势、释放姿势、持续姿势、结束姿势；束流从确定的发射点出发。迪卢克火鸟离手后独立飞行，角色进入收招，火鸟不与收招同时消失。以上是改编建议，不是已实现内容。

### 凯：近景演出与场上动作相互衔接

185.80–185.98秒是脸、手、武器附近特写；186.16秒回到场内，角色位于蓝色电弧前进结构中；186.34秒接触处出现明显红白命中层；后续仍能看到前冲方向和对手反应。电弧形成前沿轮廓，细电线提供内部运动，命中光另有色彩和形状。

对本项目的设计推论：用户提出的半屏立绘可作为短暂起始演出；场上角色必须有独立施放动作，不能用立绘遮住整个有效期来代替。刻晴应先有压低重心/拔剑准备，再按剑路给斩击轨迹，命中点独立闪光，残影最后消退。普通挥剑不需要每次铺满屏的闪白。

### 2B：远距离来自武器与招式结构

95.60秒可见薄而大的弧形刀光，随后刀光很快消退；96.20–96.44秒角色手臂、武器和身体朝向变化明显。该片段包含接续演示，不能把这些采样误当单招完整起手表。20–36秒连段展示也说明动作并非原地换光圈。

激光示例201.55秒出现细亮线，随后能看到发射位置、水平亮芯、蓝色外层，以及对方弹体/接触处的额外光效。画面明确区分细束流与较宽的接触区域；不能据可见光效外沿推断判定范围。

对本项目的设计推论：那维莱特喷水拆成发射端、水束主干、流动边缘、末端/接触水花；普通空放不产生命中爆光。长剑、长枪应由握柄、肘肩和步伐表达距离，不能单纯拉长刀光或放大整个人物。

### 补充样本：路西弗的架势与派生

另已检查[官方路西弗指南](https://www.youtube.com/watch?v=6DM3J74HwnM)的18张抽帧。263.2秒附近可见架势/悬浮武器；281.1和299.0秒是由该结构发出的不同方向攻击。317.0与352.9秒是不同必杀特写。这里的架势不等于状态型大招，但可借鉴“进入状态后使用独立动作”的组织方式，不能只给常规动作换颜色就算完成状态机制。均匀取样尚不足以确定状态进出时机或完整转换规则。

## 对当前探针的具体修正方向（设计，未验收）

1. 先补基本姿势演示：微动站立、行走、蹲伏、站防/蹲防、受击、浮空、倒地、起身。逐状态验收脚底锚点和轮廓，不能仅给按钮却使用同一张站姿。
2. 每招写清起手姿态→出手轨迹→命中反馈→收招。光效参数跟随武器/手部锚点；角色身体也必须变化。
3. 每个特效至少区分预备、主体、接触和残留。并非所有招式都要四种图元；空放时没有接触光，场上残留不能延长角色硬直。
4. 必杀立绘、场上施放动作、判定有效期分开。状态型必杀另建状态期间的站姿、移动和攻击动作，暂不批量制作；不能所有 Q 都处理成一段巨型爆炸。
5. 用黑白轮廓检查识别度，用无特效模式检查姿势。若去掉光效就不知道角色在做什么，应先修动作。
6. 击中、防住、挥空分别预览。特效外沿和攻击判定分别显示，避免视觉扩大导致实际攻击距离误读。

## 下一步实验建议

先集中两个样例，而非立即再重画十四位：刻晴检验剑路、瞬移、残影；那维莱特检验发射锚点、持续束流、接触反馈。二者分别覆盖短促斩击与持续技能。随后再迁移到迪卢克火刀/火鸟、绫华冰风、纳西妲领域。每次先对照参考和静态关键帧，再做时间序列，最后评估图元更新与重叠成本。
