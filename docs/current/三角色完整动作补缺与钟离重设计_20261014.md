## 钟离新方向

本项目改编方向：**立得住、动得少、发力明确、收势从容**。沉稳通过动作路径、支撑与节奏表达，不能仅将旧动画播放减速。

- 上身保持舒展和较直立姿态，头颈随胸廓稳定；普通攻击避免深弓步前扑、含胸低头和大幅后仰。
- 走路用短步完整承重，冲撤用紧凑移步与明确制动。跳跃保留正常蹬地、收腿和落地，不用花哨翻滚。
- 前掌防御，肘靠近躯干；受力主要在膝髋短移，不做拳击抱头、耸肩和连续甩臂。
- 枪路走短直刺、短拨、单次定向压枪；重攻以脚底、腰背蓄力体现分量，结束停住枪尖，再原路收枪。不是所有动作都旋枪、飞扑。
- E施术用合掌/下压定式，Q用直立确认和命中后的定式，人物不会追着陨星飞。完整柱体、陨星与身体分层。
- 投技用接腕、短牵引与掌推体现控制；胜利用饮茶停留，起身从同向倒地稳稳撑起。受击仍正常失衡和倒地，不以角色气质改变硬直、霸体或无敌。
- 发尾和衣摆只作适量跟随，不能以大幅飘动代替主体发力。人体比例、骨长、鞋底和枪长继续以同角色母版复核。

25组完整分镜见[钟离重设计卡](../../outputs/three-role-redesign-20261014/zhongli-design-v2.json)与工作台表格。重审次序为待机/走退/冲撤/防御 → 轻1/2/3与站重 → 蹲空攻击 → 受击倒地起身/投技配对 → E/Q及结算。旧素材只作对照，重新审过后才决定逐组保留或重画。
