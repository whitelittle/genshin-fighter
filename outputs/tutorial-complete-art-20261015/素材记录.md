# 教学素材候选

原图全部使用内置 image_gen 生成。`source/low-v1.png` 与 `source/air-v1.png` 相邻姿势碰接，作为未采用历史保留；实际接入分别使用 crouchLight、crouchHeavy、airLight、airHeavy 四个独立组。

`index.html` 可逐帧查看，三个 prompts 文件保存完整提示词，`import.json` 保存切帧、尺度、锚点、图元与来源哈希。原图、旧身体数据未覆盖；拟合只处理新帧并核验量化目标逐像素一致。丘丘王被投原图朝左，导入时镜像到统一朝右母版，游戏按面向再翻转。

美术候选尚待精修：部分空重剑尖贴边，姿势之间的武器长度、握持、服装细节和抓投贴合可后续逐帧改。固定反应伤害与持续时间为格斗教学改编，不是原作完整精通、抗性、附着量或月反应系统。
