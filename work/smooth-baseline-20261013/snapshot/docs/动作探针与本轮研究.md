# 动作、距离与特效研究：第一轮

更新：2026-10-03。本轮以设计与动作探针为主，不把未来设计直接写进正式联机战斗。选人界面的字号、提示及按钮边框是本轮实际 UI 修改。旧包、旧素材及旧文档全部保留。

- 【已实现·本地探针】`outputs/action-probe/index.html`：45 位现有角色的像素姿势查看；14 位角色、42 个 A/E/Q 动作候选，迪卢克 E 三段分别查看；逐帧、慢放、距离、方向、假人、判定、效果简化、参数编辑、截图与设计 JSON 导出。
- 【资料与目视核验】9 位角色官方拾枝杂谈录像，162 张抽帧；原片、时间及截图在 `assets/action-probe/references`。抽帧含场景和技能菜单，不能把每张都称为有效动作参考。
- 【待补资料】绫华、温迪、可莉、达达利亚尚未补齐本轮官方实机抽帧；魈视频下载被 403 拒绝。五人的候选以已有技能资料为起点，不能称为目视复刻。
- 【模型验证】`outputs/action-probe/verification.json`，检查短剑/大剑距离、一次命中门控、喷水间隔、跳越、防守、火鸟离体、零伤害领域、雷楔追斩与投弹高度。
- 【尚未实现】新像素逐帧动作、完整单人战斗 AI、领域增益/生命消耗/装置清除等机制、正式战斗中的这些新特效与新数值。结构角色是动作示意，不能冒充新完成的人物动画。真假人也没有真实受击位移、硬直或回滚。
- 【真机待验证】GIA 官方显示、加载时间与手机帧率；本地浏览器画布流畅不代表千星图元性能通过。

## 平衡以距离、风险和反制为单位

统一 60 帧/秒与世界单位；成年角色参考身高约 232。距离为攻击者初始脚点到攻击判定最远边界；对手中心与受击框边缘不同，所以中心略超过射程仍可能碰到身体边缘。突进距离不能再次加到已包含位移的射程上。

这些都是第一轮数值候选，不是已经平衡好的胜率数据。普攻不应全部同长同快；远距离、追身、对空、无敌、连段安全性不能同时给满。先比较近、中、远三档的命中/空挥/被防，再处理墙边、起身、浮空与连段衰减。被防优势示意为防御硬直减去接触后的剩余有效帧与收招；飞行弹须用接触当帧重算，不能直接套演员释放时刻。

格斗研究依据：[GGST 官方入门](https://www.guiltygear.com/ggst/en/howto/)提供进攻取消及防守脱困的资源机制范例；[官方 2.03 调整说明](https://www.guiltygear.com/ggst/en/news/post-5223/)讨论长距离招式空挥收招、被防退距和连续命中稳定性。因此本项目采用明确取消窗口、长距离招式风险、受击与非受击场景分开评估的设计方法；不会照抄该游戏的具体帧数。Street Fighter 官方页面抓取受限，本轮不引用未经读取的当前帧表。

## 四个优先特效

**火鸟**：起手聚火→横扫释放→鸟体飞行→尾焰衰减。鸟体是判定，长尾及羽毛仅装饰；每目标一次命中，不能因鸟经过多个有效帧重复伤害。角色收招与鸟生命周期分开。

**刻晴剑影**：投楔用小尺寸菱形与落点标志；追斩沿有限距离切入。必杀先局部剑影再终斩，只终斩一次伤害。残影不额外加载整套角色矩形池；优先共享轮廓或少量刀光。

**喷水**：蓄力球→连续窄水流→收束。水流每十帧一个接触窗口，共六次；候选总伤害36而非每次36。透明外缘与主体分层，避开血条，不能凭视觉大水幕扩大受击范围。

**智慧殿堂**：底部范围环、低透明拱顶、稀疏叶纹。演员完成布置后领域仍持续；领域本身零直接伤害。标记强化、持续时间与离区规则尚需正式机制实现，探针不会假装已实现增益。

其他效果用投射、弧形斩、竖向落区、布置、固定领域五类生命周期组织，但角色外形与武器动作仍须独立画帧。手机简化减少装饰、辉光与线条，不改变判定、命中时刻和网络状态。

千星接入前建议先试：近战刀光 20–60 个可见矩形、投射主体 40–120、领域装饰 40–100；这些是待测预算，不是容量结论。池由本场两角色所需效果决定，避免45人效果同时常驻。绘制更新只写变化的位置/尺寸/颜色，可降装饰更新率；逻辑仍60Hz。命中停顿不可由特效加载阻塞产生，也不要借“冻结帧”解释真机一秒延迟。

## 单人 AI：下一步可实现规格

输入仅包含延迟后的公开状态：双方位置、可见动作阶段、公开装置/投射物、血量及资源；禁止直接读玩家本帧按键和未来命中。状态机为观察→接近/保持距离→牵制→防守/对空→命中确认→收招反击→脱离。

每角色引用同一招式数据，但采用不同目标距离：刻晴/达达利亚贴近，迪卢克/长枪维持中距，那维莱特/温迪拉开，纳西妲/八重先布置。决策频率与反应延迟独立；不能把每帧重复随机选择造成的抖动当成灵活 AI。轻/中/难候选反应分别26/18/12帧，另加防守失误与连段长度上限；难度不靠伤害翻倍、零延迟读指令或凭空射程。

探针当前只做公开起手后18帧防守的简化示意，不处理距离策略、完整进攻、真实硬直和资源。正式 AI 接入模拟输入层，使用可存档随机种子、决策帧与观察队列；在回滚快照中一起恢复。验收包括面对空挥后反击、跳入对空、远距推进、装置清除、低血退出风险，以及回滚前后相同输入一致。

## 从探针到游戏的动作工作流

1. 在官方原片定位动作区间，记录来源、时间、视角；细抽起手/释放/接触/归位。
2. 画固定脚底和骨盆锚点的关键姿势；检查剑尖路径、身体重心与原作辨识度。先解决刻晴普攻/追斩，不靠更大光效掩盖姿势问题。
3. 在探针设置距离、帧数与判定，对照站立/跳跃/防守；把通过的动作 JSON 和截图交回生产入口。
4. 拟合像素与矩形后记录源图尺寸、矩形数量、别名/重复帧、峰值可见池。原作参考与设计资源不打进游戏 GIA。
5. 接入动作状态、取消、命中门控、特效生命周期及回滚快照。逐帧命中与联机确定性复测，再导出独立新 GIA，保留旧包。
6. 真机验收动作辨识、遮挡、读条、控制与攻击瞬间卡顿；只把实际观察写入真机结论。
