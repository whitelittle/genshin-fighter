# 原神格斗 Demo

更新：2026-10-02。角色采用用户允许沿用的当前刻晴与迪卢克造型，不继续纠正武器细节。此前单人v0.5及联机v0.1归档保留。新增demo仍分为两个独立存档与GIA。

## 试玩入口

- 单人AI：[游玩页面](http://127.0.0.1:4192/editor/play#genshin-fighter-demo-solo)。默认刻晴对迪卢克电脑，可点击选择迪卢克，电脑随之换成刻晴。
- 双人：[游玩页面](http://127.0.0.1:4193/editor/play#genshin-fighter-demo-online)。在游玩页选择二人模式；玩家1/玩家2各控制自己的角色。可暂停并切换玩家视角对照。
- 若服务未运行，分别运行根目录启动格斗原型.ps1和启动双人格斗原型.ps1。编辑器载入outputs/demo-solo-light/fighter.save.json或outputs/demo-online-light/fighter.save.json，进入游玩页；URL必须携带会话ID。

## 操作

数字方向以角色当前朝向为准：2=下、3=下前、6=前。

| 操作 | PC | 触屏 |
|---|---|---|
| 左右移动/蹲下 | A/D/S | 左侧八方向摇杆，可按住拖动 |
| 跳跃 | 空格 | 跳跃按钮或摇杆上方向 |
| 轻/重攻击 | J/K | 轻/重攻击按钮 |
| 上段 | 前方向+K | 摇杆前+重攻击 |
| 下段 | S+J | 摇杆下+轻攻击 |
| 站防/蹲防 | L / S+L | 防御 / 摇杆下+防御 |
| 必杀 | 236+J或K | 下→下前→前，再按轻或重 |
| 挑飞 | 623+K | 前→下→下前，再按重 |
| 超必杀 | 236236+K，需要100能量 | 两次下→下前→前，再按重 |
| 重开 | R | 重开按钮 |

轻攻击命中后可以接第二次轻攻击，再接重攻击或搓招。挑飞后可跳跃轻攻击追击；浮空追击最多5次，伤害递减，重攻击/必杀加速下落。倒地后不能行动或被继续攻击，起身带18个逻辑帧保护。比赛三局两胜，单局60秒。

能量通过命中、受击及少量随时间积累；超必杀消耗100，仍可防御。刻晴为天街巡游，迪卢克为黎明；此demo采用单次伤害与当前动作反馈，完整演出和多段招式仍待扩充。

## 文件与性能档位

每档有独立单人和双人目录：outputs/demo-solo-档位、outputs/demo-online-档位。目录中含fighter.save.json、fighter.lua、GIA和build.json；双人另含server-logic.json。

| 档位 | 目录后缀 | 每个角色常驻图片池 | 两人图片池合计 |
|---|---|---:|---:|
| 精细 | fine | 6386 | 12772 |
| 标准 | standard | 4242 | 8484 |
| 轻量（默认） | light | 2275 | 4550 |
| 兼容 | compatible | 1631 | 3262 |
| 最低 | minimum | 939 | 1878 |

池大小取两种角色所有关键姿势的峰值，以支持换角色；当前画面可见图元通常更少。UI、场景和容器控件另计，不能把此表当作总控件数或帧率承诺。五档保持人物世界尺寸、判定、60Hz逻辑、伤害、能量、搓招窗口及同步协议一致。换帧仅在姿势/角色改变时写入池；移动由父容器承担。

## 验证及当前边界

已完成模拟器战斗回归、超必杀/角色/场景/触屏拖动测试以及双人暂停逐像素一致性检查。报告在轻量目录verification.json与feature-verification.json；素材拟合重建与五档负载在assets/demo/load-report.json。五档运行战斗轨迹一致性记录于assets/demo/quality-verification.json；手机16:9、19.5:9及4:3三个模拟画布均通过操作控件边界和触屏236测试，报告assets/demo/mobile-verification.json，这不代表真机多点触控已经验证。

人物每角色目前4个完整关键姿势：待机、起手、横斩、挑飞，按招式逻辑阶段切换。走路、蹲下、防御、受击与倒地使用这些图及变换反馈，尚不是完整逐帧动画。三张场景当前是可切换的程序块面示意；UI为可用布局，未达到DNF Duel最终画面水准，暂未加入配音和完整音效。

联机是模拟器内两个独立客户端，由玩家1推进战斗并广播快照，玩家2展示同一状态。本轮增加同步角色、场景及能量。尚未验证真实两台设备的延迟/丢包/断线或回滚。GIA只包含UI与客户端Lua，模拟器server-logic.json尚需转换为千星官方服务端节点规则后才能作为真机联机交付，不能仅导入GIA就声称真实联机已完成。PC及横屏触屏布局已绑定，手机多点触控与实际性能仍需设备验证。
