# 九角色个人特色技能设计备选 v0.1

2026-10-13，来源：匿名玩家反馈角色区分度与乐趣不足；用户认可通过不同赢法提高区分度，要求参考原神，允许调整动作模组、设计特殊闪避，并加入那维莱特、钟离、玛薇卡。

**状态：设计备选，未实现、未进行模拟器或真机验证。** 当前六角色稳定版不变。数值平衡后续调整，本稿先定义玩家的选择、技能循环、对手反制与动作需求；不锁定伤害、帧数、冷却和资源阈值。用户最新分工：动作核验及尺寸修复由另一对话负责，本对话只记录情况与提出设计需求，不核验、修图或接入新动作。

## 1. 设计原则与范围

- 每位角色有一句能被玩家体验到的核心玩法，并在常用普攻、移动、E中体现；不能只在Q演出区分。
- 优先一个核心机制加一个兑现方式。备选机制不全部叠加；先验证核心是否有趣，再决定扩展。
- 同样按键可以因角色或状态产生不同招式，轻/重/方向/E/Q沿用现有操作入口。精确操作映射待原型，不在手机增加九套额外按钮。
- 不立即引入整套元素反应、命座、装备或原作队伍后台增益。保留原作辨识度，按横版对决改编，不逐条复制开放世界机制。
- 数值可以后调，但技能能否防御、打断、惩罚、撤销、绕过属于机制定义，现在就要写清。
- 明确无敌、霸体、护盾、攻击闪避的区别：无敌期间不成立对应命中；霸体通常仍受伤；护盾消耗耐久；只避某类攻击的闪避需要明确范围。视觉隐藏不等于规则无敌。
- 多人/车轮战：专属资源原则上归角色；被击败后清理其标记、召唤、柱体和场地效果，不由下一位继承。胜者仍在场时按该角色规则延续，回合重开/重赛另行重置。后台供能与队伍接力增益只作后续备选。

## 3. 雷电将军：蓄势拔刀

**原作参考：** 雷罚恶曜之眼协同攻击、愿力、梦想一刀与梦想一心。原作参考取自本地技能资料；下述愿力获取和格斗用途为本项目改编。

**主方案：** 常态长柄重视剑尖外的中距离控制，贴身轻攻只用于防身。E授予恶曜之眼：本体明确命中的特定攻击后触发一次有间隔的协同雷击，构建稳定的命中节奏；格挡不自动提供相同奖励。成功命中/完成指定战斗行为积累愿力，不能待机无风险自动攒满。

Q先梦想一刀，再进入限时拔刀模组。刀态轻攻侧重近身连续压力，重攻侧重兑现，取消路径与长柄不同；愿力影响可用强化选择或状态资源，具体数值以后定。玩家要决定带多少愿力入场，以及把有限刀态花在追击、压制还是反击。

**反制：** E施放可被打断；对手可以防住协同节奏、拉开刀态优势距离并惩罚结束空窗。拔刀不默认全程无敌/霸体；满愿力不允许无限压制。先有完整“开刀→强攻→退回常态”的循环。

**动作需求（交其他对话评估）：** 独立拔刀准备/退刀、刀态代表轻重攻与常态差异。备选B为愿力只强化一刀，制作更小但常态区分较弱。原作后台供能不纳入第一版。

## 4. 纳西妲：挂印与延迟陷阱

**原作参考：** 所闻遍计取景、蕴种印、灭净三业与摩耶之殿。原作多人连结改编为单对手的印记时机博弈。

**主方案：** 轻攻是近身脱困、较短的法术牵制；重攻预设前方可见的草种区域，有明确铺设动作。E点按近处挂印；按住进入短暂取景姿态，以更远距离挂印，但站定且可被打断。不是全屏自动选中。标记本身不反复无条件扣血。

标记中的对手遭到本体或草种的有效命中后，安排一次可读的延迟三业；延迟/触发次数有界，不自触发循环。玩家可利用延迟覆盖追击或换位，对手可以防御、离开作用区或在她布置时抢进攻。草种为可见、可规避的独立攻击来源，不附无限追踪。

Q展开摩耶之殿，强化这套布置的覆盖/重置选择，保留站位意义；不再仅作为通用三段高伤动画。领域内也必须存在可守、可逃的间隔。

**动作需求：** 取景起收势、草种布置与触发提示；身体与标记/种子独立。备选B：一次命中消费标记，重挂才有下一次强化，先用最小闭环验证。备选C的元素反应联动留到后续，不与第一版叠加。

## 5. 芙宁娜：伙伴指挥与舞台节奏

**原作参考：** 三位沙龙成员、众水歌者和气氛值；第一版优先用沙龙伙伴建立主动选择。

**主方案：** 本体剑术保证基本攻防，E按方向/连按选择伙伴指令，精确输入留待手机原型：蟹负责低位近身威胁，海马负责较远的直线牵制，章鱼负责延迟覆盖。三者攻击线与时机不同；不以三种特效执行同一击代替区分。共享指挥资源，一次只保留一个正在执行的攻击指令，伙伴回来/休息后才能再调度。

玩家先让伙伴逼对方选择，再由本体攻击/投技跟进。命中、主动牺牲机会或明确战斗事件积累舞台气氛；Q允许一段有限的强化指挥或一次伙伴合奏，第一版优先强化指挥，让身份在普通对局中持续体现。

**反制：** 指令动作可被打断，伙伴攻击有预告和空隙；本体受击时不立即无限取消已启动攻击，也不无限自动反击，需要明确“未启动取消、已启动完成后停止”的规则候选。本体防御与伙伴自保分开，不能召唤后只站着格挡。

**动作需求：** 三种指令姿/提示与伙伴攻击时间线。备选B才加入歌者模式：放弃进攻获取有限恢复，准备长、受击中断、不凭切换持续重置恢复；防止车轮战拖时永动。原作全队扣血/治疗不机械搬入第一版。

## 6. 神里绫华：霰步与现身反击

**原作参考：** 神里流·霰步隐入碎冰并在现身后冰附魔；原作移动隐身不作为无敌证明。**格斗版短暂无受击判定是用户允许的改编备选。**

**主方案：** 方向+闪避执行固定可控距离的入冰→潜行→现身。潜行的一个明确阶段移除受击判定，可避开打击、飞行道具和投技；入冰准备及现身恢复不享受同样保护。不能从受击/格挡硬直随意脱出，不能无限潜行，冰痕提示当前位置，不在潜行中攻击。第一版不穿过对手/场地边界，以减少隐形左右换向；过身作为备选B单独评估。

现身后的短时冰剑资格可用于一次居合强化或冰华接近反击。玩家可以立即出剑，也可以不兑现并调整距离；未命中不能无限刷新潜行。E冰华负责近处反击/对空，空挥有收招；Q霜灭采用可防御的持续前进冰风，制造有限推进机会，区别于自动拉入演出。

**反制：** 对手观察冰痕，延迟攻击覆盖现身或逼她往角落退；无敌阶段不受伤不代表现身反击必胜。读出并惩罚现身是此角色的关键对抗。

**动作需求：** 入冰、潜行提示、现身、冰剑衔接；无敌窗口是模拟规则，与图像透明度解耦。备选C仅避打击/弹体、可被专用投技抓住，属于另一个方案，不能与主方案混写“完全无受击判定”。

## 7. 克洛琳德：常态剑术与夜巡枪剑双模组

**原作参考：** 夜巡把普通攻击改为驰猎枪击，把战技改为贯夜突刺；生命之契连接两者。本地技能资料已包含该结构。

**主方案：** 常态保留连续剑击、近身防御与重击枪击。E有明确切换准备，进入限时/有限资源的夜巡模组；轻攻改为枪击，重攻改为有推进选择的贯夜，E再次按下可做指定贯夜或退出，输入方案二选一待原型。夜巡的低位、空中和对空招式要独立定义，不将地面枪击直接贴到全部动作。

驰猎建立契值，贯夜消耗契值并因资源档位改变突刺性质（例如更远推进或追加斩，二者不都默认获得）。低资源也可贯夜抢位置，但收益更小，可能浪费之后强化。资源获得优先要求命中/有限确认，防止远处无限空射后满资源突刺。

Q提供一次突入确认和夜巡衔接机会；是否直接授予契值为备选，不同时默认赠送满资源、刷新持续和无敌。

**反制：** 枪击高度与间隔可读，允许跳过/防住接近；切换不能自动取消被压制状态。贯夜有空挥/被防的惩罚，不把高速突进默认当完全无敌。

**动作需求：** 两套攻击模组以及切换/结束/枪击/贯夜代表姿。先定义一组地面核心轻重攻再扩完整八类，动作核验交另一对话。与玛薇卡区别：克洛琳德侧重“命中蓄契、精确突刺兑现”，并非惯性载具抢线。

## 8. 阿蕾奇诺：挂印回收与红死镰

**原作参考：** 血偿勒令、成熟、回收生成生命之契、强化攻击消耗契值、Q回血。生命之契为自身资源，不直接解释为让对手不能治疗。

**主方案：** 常态长柄以中距离横扫和低位钩斩为特色。E命中施加勒令，印记经过可见阶段成熟；重攻有专用回收分支，需要站在合理距离并完成回收动作。可提早回收取得较少资源抢先施压，也可等待成熟，承担被对手抢进来的风险。对手不因有印记而被必然禁锢。

回收后红死镰改变代表普攻的攻击形状、推进和取消选择，攻击消费契值。强调长柄控距与镰刃拉回/压起身的机会，不只乘上伤害。Q为一次结算与有限恢复，消费或重置现有契值，形成继续进攻还是撤回资源保命的选择。

**反制：** E/回收可打断，挥空可追打；回收只消费自己的有效标记，一次印记不能重复领奖。对手可以趁未成熟进攻、逼她早收、拉开回收距离，避免等到强化后只被动挨打。回血不允许低风险反复循环。

**动作需求：** 挂印提示、早/成熟回收、红死镰代表攻击衔接。已有高评价动作尽量承接；是否重做由动作对话判断。与克洛琳德区别：先对手挂印/成熟再回收，而非自己枪击蓄契后短周期突刺。

## 9. 那维莱特：蓄水与水束通道

**原作参考：** 源水之滴缩短蓄力并回血、衡平推裁持续水束。本地存在技能资料与动作候选；两批来源不默认同版本。

**主方案：** 常态掌波/杖式保持中距离，重攻按住蓄力，释放进入持续水束。E水瀑命中或完成明确事件后产出自身可用水滴；水滴决定更快开束或留下恢复/后续机会，获得和消费要可见。无水滴可慢蓄，不作为免费瞬发。

水束有固定方向、覆盖线与明显启动，可缓慢移动，期间不能高速掉头/自由转圈；第一版不能用横版射线扫描整屏。允许主动提早收束以防接近，但收束仍有成本。Q制造水瀑和新的水滴/站位局面，不只是另一段自动三连演出。

**反制：** 逼近蓄力、在开束前越过攻击线、跳过定义好的射线高度或从盲区进攻；对空/贴身弱点要保留。吸滴恢复与水束耗血只是备选B，第一版先验证站位与蓄力循环，避免恢复永动。若保留耗血，不能自耗直接KO且需清楚显示。

**动作需求：** 蓄水、开束/维持/收束、轻微移动水束的root衔接。用户称仓库有动作更新，本次仅记录其存在，未做选版或动作质量核验。

## 10. 钟离：岩脊阵地与有限护盾

**原作参考：** 地心点按岩脊、长按玉璋护盾，天星石化。

**主方案：** 长枪保留稳健中距离，E点按在限定前方位置立一根岩脊，可挡部分弹体并按预告节奏共鸣；不直接成为整屏伤害来源。E长按准备更久，取得有限耐久护盾；两种施放共享机会/资源，不能连续铺柱加永久盾。

第一版岩脊是可破坏的战斗道具，不阻塞角色行走、不改变舞台地面物理，也不能卡死角落；阻挡走位属于后续备选B。护盾抵挡伤害仍消耗耐久，受击/格挡/投技规则独立定义，不能等同无敌。投技绕过护盾保护作为主反制候选。

Q天星有预告与判定范围，命中后用短石化奖励站位/确认；防住或空挥不石化，不叠加永久控制。石化结束后的追击设衰减或一次控制限制，机制现在明确、具体数值后调。

**反制：** 抢长按准备、拆柱或越过柱体压力、投技威胁盾内站桩。钟离不能同时拥有最好突进、无限盾和不可防天星。

**动作需求：** 立柱/举盾起收势、盾破/共鸣提示、天星命中/防住两分支。仓库更新只登记来源待动作对话核验。

## 11. 玛薇卡：大剑与驰轮车抢线

**原作参考：** 大剑/驰轮车双战斗形态、焚曜之环、夜魂与战意。官方5.3介绍明确展示大剑与骑乘两种战斗风格。

**主方案：** 徒步大剑起手较明显，重击用于读招，轻攻用于近身确认。E进入驰轮车；骑乘替换代表普攻和移动为前进斩、冲线、刹车/掉头，夜魂持续消耗。玩家决定抢空间和烧资源，还是下车稳打。冲线有可读路径，不能全程无敌；转向/刹车留下可追击的间隔，不把车仅当更大的特效。

通过主动交战与消耗夜魂积累战意，Q消费战意执行坠日斩，再取得一段有限骑乘进攻机会。沿用现有Q键显示专属战意，不另加普通能量叠第三条复杂资源。夜魂负责骑乘续航，战意负责Q，二者用途分开；最小原型可先只做夜魂加普通Q，再评估战意。

**反制：** 防住冲线、诱导冲过头或进入角落、抢刹车与上下车恢复。不能用高速+霸体+无敌同时覆盖所有时机。骑乘体积更大不自动扩大人体受击框，载具是否可单独被击破属于备选B。

**动作需求：** 徒步/上下车/骑乘攻击/刹车/转向和有限跃起，不把静态人车整体平移当完整骑乘模组。焚曜之环为备选C：徒步时短暂火环压迫，第一版不同时加入多套自动后台攻击。仓库已有骑乘候选与更新，未经本轮动作核验。

## 12. 实施前的技术备忘（未开发）

1. 两套模组切换用角色状态/计时器和明确定义的招式表，不运行时替换全局共享函数；角色编号追加，不重排六人旧ID。
2. 无敌类型、阶段、标记所属、契值、愿力、伙伴指令、水滴、柱耐久、夜魂/战意及模组状态进入确定性快照；渲染透明和临时控件不作为命中依据。
3. 同一战斗拍统一处理输入→切换/资源事件→命中→状态结束顺序，消除“看起来潜入却仍被打中”的回滚歧义；精确顺序在原型时写入规则。
4. 新召唤/水束/柱/载具做有限数量和持续时间；先核算同屏双角色、双方镜像、双缓冲/隐藏池和换帧更新成本，不能靠增加图元堆玩法。
5. AI按角色循环选择，而非共用“E好就按、Q满就按”。先让普通AI展示玩法并留出反制；难度调整反应、决策质量与失误，不读取尚未确认的玩家输入作弊。
6. 原型验收看：玩家能说出怎么赢/怕什么/如何反制；不用Q时仍有明显差异；防住/挥空/成功回避能观察到后果；换角色确实换决策。之后才进入数值平衡与动作预算验收。

建议试验顺序：绫华霰步与克洛琳德双模组各自最小原型 → 仆人回收循环 → 伙伴/标记 → 三位新增角色。此为设计建议，不代表已经排期或开始开发；动作更新由负责对话先明确可用版本。
