# 当前设计基线

更新：2026-10-03。本文件只记录本项目的当前设计；技术复用资料在 share 目录。较早两角色、取消三人等决定留作历史，不替代此处最新范围。

## 比赛和角色

双人优先，双方各选三位不同角色，依次用于 **ROUND 1、ROUND 2、ROUND 3**。三局两胜，提前两胜即结束，不在一局里接力。游戏显示不使用 R1/R2/R3 简称。若娜瓦暂不制作。

当前候选有 45 位可选角色。普攻选用原作 A 的动作意图，E 改编为特殊技，Q 改编为必杀。刻晴投楔/瞬移与单次命中的多方向斩视觉、迪卢克三段火刀与火鸟为已有方向。后续精细动作按用户提供的设计接入；十二关键姿势及姿势代用不等于所有动作逐帧完成。

有站立、移动、跳跃、蹲伏、上下段攻击/防御、受击、浮空、倒地和起身。技能复杂后台机制采用格斗改编，平衡和特性可随真机反馈继续修订。

## 选人

中央两个展示框靠近，左右各三栏位明确标为 ROUND 1/2/3，名字显示在已选栏和中央展示。头像网格不放长名字，每页十人，可扩展；完整保留帽子、耳朵与头饰。蓝色标记一方、红色标记另一方，未选头像灰色。

选择后才构建展示，避免全部角色站立动画同时常驻。当前实现是完整头像展示，站立角色预览尚未接入。点击已选项可撤回并前移，锁定后不修改；三人未选满不能准备，双方资源未加载完成不能开战。

选人不显示地图。指定权威端随机地图并同步，同一比赛保持地图。角色按场加载；下一场黑屏切换，退出卸载多余战斗资源。

## 视觉与操作

本次 UI 修订方向：圆润的头像卡、阵容栏、展示框与操作按钮，深蓝底、柔金轮廓、双方蓝/红强调。边框少量原生图形组合，保留像素角色轮廓。明确选定、未选、锁定和等待状态，避免只靠装饰传达操作。

战斗 HUD 保留头像、血量、能量、胜场、计时与必要状态；多余说明进入 H 指令表。PC 隐藏触控按钮，手机保留摇杆与简化按钮。E 特殊技、Q 必杀；J 轻攻、K 重攻、L 防御、空格跳跃、S 蹲伏。

地图为略俯视地面与横版角色，背景保留大树/神像、蒙德城门/教堂、风龙废墟高塔地标。当前地标是原生几何图形候选，不宣称达到正式美术质量。

## 当前与后续

已实现候选：分页选人、三栏位顺序、联网快照、按场资源门槛、两胜结算、双方再战、重选与回首页。后续：精细动作与过渡帧、入场/胜利演出、特效品质、同角色衣服配色、AI、接力补充包。未完成项不能显示为已经验收。

## 动作视角、演出与补帧（2026-10-03 用户最新修订）

【用户要求】场上技能动作与站立、移动、普攻保持同一横版视角、人物比例和脚底基准。大招图/立绘不能作为场上的动作帧；技能特效从手、武器或地面相应锚点产生。独立立绘演出与场上角色动作分开。当前像素逐帧动作尚未重画，不把探针结构示意视作完成素材。

【待讨论设计】加入入场和胜利动作候选，先加法，最终依实际成本减法。刻晴：雷楔先进入落点，电光闪现后刻晴就位；迪卢克：火鸟进入落点、炸开，迪卢克在爆炸位置显现。入场不产生攻击判定。胜利动作方向为刻晴收剑、迪卢克垂剑与余火熄灭；这些具体动作、演出时长及是否只在第一局完整播放仍待确认，未制作。

【用户允许】部分动作适当补充动画帧，以完善视觉；不是要求所有角色、所有状态统一加帧。

【制作建议，非已验收数值】先补明显跳变的连接：蓄力到出手、武器挥过有效位置、收招到待机、浮空到倒地、落地到站稳、倒地到起身。短促斩击保留清楚的准备与收势，最快的挥击可用少量跨幅帧；持续喷水优先增加稳定施放循环，避免每帧大幅换姿势。待机采用小幅呼吸循环，避免过度晃动。加帧后仍保持攻击节奏，不以平均插值填平所有动作。

【实施约束】动画显示帧与60Hz战斗模拟帧分开。补显示帧不自动延长起手、有效期、硬直或入场等待；动作阶段的时间和判定独立管理。优先给刻晴与那维莱特样例验证，再按收益扩展其他角色。评估每帧新增图元、帧间差量更新和当前角色池成本，不让所有候选动画常驻。只保留候选记录，正式性能与真机视觉仍待验。
