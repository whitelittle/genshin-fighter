# 绫华格斗动作重制规格

2026-10-10。设计候选，由用户要求重做完整格斗动作推动；以下招式结构与参数需要舞台对照，尚未成为游戏实现或用户验收。

## 共同制作与舞台规格

以同一持械站姿确定头、肩、髋、膝与刀长比例。逐帧ROI保留源坐标与显式root；站立高度是参考量，不把蹲、倒地、举刀的包围盒缩成相同高度。每套源图记录源像素到世界单位的同一倍率；禁止按帧外框独立缩放。先以关键姿势核对身体比例，再降色拟合，细节预算单独报告。

身体、握持中的刀和刀鞘作为完整姿势共同设计。刀鞘固定腰侧，刀柄、握持手和刀尖都有明确轨迹。左右朝向由整套坐标镜像；动画内部不换镜头、不突然换手。有效帧中刀须可读，特效关闭后仍能识别攻击方向。

舞台采用V3原展示页的角色/对手、影子、世界地面、逐姿锚点、帧时间线与独立特效组织。步行使用支撑→通过→另一脚接触的步态周期和持续根位移；跳跃按离地→上升→顶点→下降→落地编排。原页的正弦来回行走只是展示路径，不直接成为游戏运动规律。世界轨迹和姿势轨迹独立，预览位置变化不冒充碰撞模拟。

每招分别记录显示姿势保持、60Hz起手/有效/收招、root轨迹、刀状态、攻击框、身体受击框、推挤框、特效事件、命中/防御/空挥分支和取消。未确定数值保留未定，不按四姿各10帧默认定招。命中事件由模拟逻辑执行，显示跳帧不丢事件。

## 25组动作设计

|动作|关键姿势与武器关系|舞台／交互与连接|
|---|---|---|
|待机|右手握刀柄、左手稳鞘，刀尖和鞘位固定；小幅呼吸|双脚接地；接移动、防御与拔刀，避免腿部迈步混入|
|前走|持鞘姿态延续待机；左右脚交替，手和髋小幅反向摆动|持续前移；接触脚稳定，周期结束回到可继续走的姿势|
|后退|前脚朝对手、后脚探步，重心不交叉失守；握刀关系保持|持续后退；明确减速回待机，不能只倒放前走凑动作|
|跳跃|预蹲、蹬地、上升、收腿、下降、落地缓冲|root随跳跃轨迹；空中使用髋pivot，落地接蹲与待机|
|前冲|压低重心、蹬地滑入、前脚制动；刀鞘贴髋|阶段性前移；制动后接待机/攻击，禁止图片平移替代蹬地|
|后撤|后脚蹬退、短腾空、落脚收稳；手保留刀柄接触|向后轨迹；落地恢复防守，不能穿过对手|
|蹲下|屈膝降髋，躯干收紧；刀鞘离地不穿腿|root固定，身体受击框降低；接蹲防与蹲攻|
|站防|双手在胸前架刀，刀身近竖直形成身前防线；肘收拢|进入→保持→承受冲击→恢复；受力只小幅后退，无前挥刀路|
|蹲防|低髋、稳定后脚，刀柄靠胸腹、刀身挡身前|保持低位受击框；受力不趴地，接蹲与起身|
|轻1|握鞘准备→右手出刀横斩→刀越身前→收回|短中段；起手、有效、收招明确，刀光仅在有效阶段出现|
|轻2|承接轻1刀位，髋肩反向带回斩，后脚跟进|同链朝向和握持不变；仅确认后进入连段窗口|
|轻3|回收刀位→由肩侧斜斩→前脚制动→收刀|较大恢复；攻击框沿前方斜向，不能让尾迹全程命中|
|站重|双手蓄势、前脚踏入、大幅斜上挑、收稳|可挑飞设计候选；更慢起手与空挥惩罚，武器不扩大身体框|
|蹲轻|低位短出刀、向前横切、收回|下段设计候选；刀位与蹲姿手位置连续|
|蹲重|低位蓄势、刀路扫向对手脚侧、重心回收|击倒设计候选；根位移小，刀身完整且不穿自己脚|
|空轻|空中髋部稳定、短斜切、收刀|空中root继续运动，攻击框随root和刀路；不能把演员放地面|
|空重|上举蓄势、向前下斩、收腿、落地缓冲|空中下向刀路；明确落地恢复，不用竖直光柱替代动作|
|E|聚冰姿态、地面释放、裙摆回落、恢复握刀|冰花按世界地面定位；人物动作与独立区域事件分开|
|Q|起手确认、释放冰风、确认后完整演出、散场恢复|命中才锁双方进入完整演出；防御/空挥短恢复；风暴离手后独立运动|
|投技|接近抓取、空手控制对手、转髋牵引、释放、回握刀柄|刀须提前收鞘；双方抓点、根距和被投姿势成对校验|
|被投|失衡、牵引、腾空、摔落、缓冲、起身连接|由投方同一时间线驱动；体型与墙边需要单独检查|
|受击与倒地|站受击、后仰、失衡、倒地，刀/鞘保留明确归属|受击方向跟施攻者；击退/浮空/倒地由逻辑分支控制|
|起身|侧撑、收膝、单膝支撑、站稳、回握刀柄|倒地root与支撑点连续；连接待机，无每帧居中漂移|
|胜利|保留现有整理衣装、致意、收势设计|修复一行四姿提取、背景与尺度；不重画已可用设计|
|败北|保留现有跪落/败北收势设计|统一root与身体尺度，接回合结算；不要求全程握刀|

## 交付顺序与当前缺口

先验收同尺度待机/前走/后退与站防，再轻1→轻2/3与重攻，再蹲空动作与受击起身，再E/Q与双人投技。所有25项纳入同一台账；已有图仅供筛选，不能据此登记重制完成。

当前新持械站防v1被指出像进攻，保留为待修。站防v2已生成并提取四个主体，胸前架刀、刀身竖直，已替换当前站防预览，仍为待验关键姿势。新持械前走v2缺乏明确左右支撑脚交替且背景不透明，已登记失败，不进入前走播放。

舞台已加入独立root的前后走、跳跃、前冲/后撤预览轨迹，加入V3雷电参考对手与影子。对手当前仅站立参考，不冒充受击或成对投技完成。对手反应、成对投技、攻击判定、取消与回滚尚未接入。没有新的模拟器或真机验证。前期只复用HTML的页面不算完整舞台完成。
