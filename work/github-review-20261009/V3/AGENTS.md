# V3 开发约束

先读 README.md、docs/DECISIONS.md、docs/CHARACTER_STANDARD.md。V3 是当前有效开发基线；history/r33 内作废/回退表述为历史。

client/genshin_fighter.lua 是认可的 E 基线。source/ 加载块按 order.json 拼接必须字节一致；改动时同步正式客户端与哈希，禁止只改副本。

运行标准清单中的两组 Lua 检查、源码重组和素材哈希检查。模拟改动额外验证确定性与回滚；界面改动查看桌面和手机截图。大规模扩池、同步释放、坏补帧或混入高清包不得进入正式版。

设计/模拟器/真机/推断分开写。保留旧资料但不覆盖较新决定。新角色设计卡为候选，没有素材或实机验收不得标记完成。先刻晴，再迪卢克，逐个验收。

文档遵守根目录匿名与隐私规范；不要提交个人账号数据、凭据、下载辅助文件或带个人用户名的本机路径。
