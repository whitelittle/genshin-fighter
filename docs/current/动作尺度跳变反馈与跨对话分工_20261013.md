# 动作尺度跳变反馈与跨对话分工

2026-10-13，来源：匿名玩家。状态：**P1待修复，动作核验与修复由另一对话负责；本对话仅记录。** 本条没有逐帧分析、定位根因、调整素材/倍率或生成修复GIA。

用户明确反馈：同一角色站立一个大小，移动或受击时变成另外一个大小；问题指实际人物身体尺度变化，不是镜头变化。此前300动作首尾显示倍率检查不能证明源图人体比例、移动/受击中间姿以及实际消费数据已统一，不能沿用“尺度已经彻底修复”的结论。

修复目标仍为同角色统一人体尺度，保留蹲伏、跳跃、扭转的自然姿态变化及不同角色身高差。武器、光效、衣摆伸出不应导致身体缩放；不把所有姿势外框强行等高。用户未指明仅一位角色，按当前六人均可能受影响记录；那维莱特/钟离/玛薇卡接入前也应遵循同标准。

交接给负责对话的最小信息：站立→移动、移动→站立、站立→受击、受击→恢复存在可感知体型跳变；需区分源图人体单位、逐帧缩放、锚点/root与运行中动作映射。具体角色、动作帧、原因和修改证据由该对话核验后补充，本对话不预判根因。

验收期望：实际游戏连续动作切换时头/躯干/四肢尺度稳定，包含关键中间帧及首尾连接；程序字段一致与矩形像素无损只是证据的一部分，不能替代实际体型观察。镜头仅用于固定观察条件，不作为当前问题的默认解释。

稳定版本冻结副本保留原状；另一个对话交付修复后，应新增候选版本并补验收记录，未经复验不回写旧冻结版已通过。
