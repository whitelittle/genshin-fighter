# 无选人双人战斗复测版

固定 P1 刻晴、P2 迪卢克，加载后直接等待席位/开战。用于绕过用户尚未接入的选人信号，先测试两台设备战斗。菜单完善、退场释放、其他角色和完整结果同步仍在后续完整测试版实施。

保留已导入的 B 图元模板。Lua 模板容器索引按用户截图填入 1073741845，脚本挂在新 A 内 FighterDemo。不要再导入 B 造成索引改变。

最小服务端：FighterHello -> P1/P2 各发 FighterSeat(1/2)；FighterJoin -> 向两人发送无参数 FighterJoined（允许重试回包）；FighterFrames(Slot,FirstFrame,AckFrame,Payload[,Epoch]) -> 发送给另一人 FighterFramesOut，原样传递参数。此临时版接受旧四参数回包，内部代次固定1，不需要 FighterSelect。

角色按实际席位容量创建：刻晴1369、迪卢克2335，头像共享760，迪卢克火鸟338，合计4802动态图片。移除启动时的三背景像素池、两个选人缩略图、刻晴席位无用的火鸟池。保持人物源素材，不减少动作。实例化阶段不再反复设置默认属性。手机耗时仍需用户测量；队列下降不等于帧率已通过。

PC 隐藏触屏摇杆与攻击按钮，保留 A/D、S、空格、J/K/L 和旧搓招；手机暂沿用旧触屏布局。完整新版再接简化操作和 H 指令表。本包不宣称完整测试版要求已完成。

模拟器两席位无选人即可收到 Joined 和 FramesOut，进入战斗；PC触屏控件隐藏。未重复全部原战斗测试，真机待反馈。旧文件未删除。
