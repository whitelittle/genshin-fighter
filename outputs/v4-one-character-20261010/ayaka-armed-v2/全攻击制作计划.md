# 绫华全攻击：分析、设计与制作

2026-10-10。按最新要求制作八种普通攻击及E/Q，保留既有上挑下砸投技；这是本项目横版格斗改编，不声称逐帧复刻原作。继续使用雷神/草神原展示模板，不新建预览工具。

## 分析

原素材把身体、刀路和特效拆开生产，握点及收招刀位不明确；单纯统一图片外框无法补救。正确顺序是完整持械关键姿势→刀路和手部检查→显式根位置/空中髋轴→判定时序→独立离手效果。武器、头发伸出不改变角色身体尺度。现有雷神/草神源码的世界位移、技能事件、对手动作可作为结构参考，不能把其图或参数冒充绫华完成品。

## 招式与顺序

|招式|身体和武器结构|攻击意图|
|---|---|---|
|轻一|稳鞘、拔刀、前方横斩、回收|短中段；单次结算|
|轻二|由前方低刀位回斩、斜上随挥、肩侧回收|连段承接；单次结算|
|轻三|肩侧举刀、斜下斩、前腿制动、恢复|连段终结；单次结算|
|站重|降髋蓄势、踏步斜上挑、收稳|挑飞设计；单次结算|
|蹲轻|保持低弓步、短前切、回收|下段；单次结算|
|蹲重|低位装刀、扫向脚侧、低位收稳|下段击倒设计；单次结算|
|空轻|屈腿腾空、短斜切、收刀|空中高段；root继续运动|
|空重|腾空举刀、斜下斩、收腿准备落地|空中下砸；落地恢复另接|
|E|持刀聚势、前方按地释放、衣摆回落|独立地面冰花；显示事件不直接扣血|
|Q|稳鞘、拔刀释放、离手冰风、恢复|命中确认后长演出；空挥/防御短分支待实现|

每组制作六个关键姿势：准备、出手、有效、随挥、回收、恢复。六姿不是完整流畅动画验收；不足的肩肘/腿/刀路过渡应补画而非图像旋转拉伸。

## 生产与验证

1. 内置imagegen，以现有持械站防v2仅作身份/比例参考；每招独立新源图，人物与握持武器一起画。
2. 保留源图与完整提示词、SHA256、逐姿ROI；按真实透明连通主体提取，不按裁切框缩放人物。
3. 单套动作固定显示倍率，脚底由足部支撑位置计算；空攻单独髋轴。跨招比例仍需播放与人工复核，不能宣称生成器已经保证。
4. 按最新要求复用已记录绫华18色加外轮廓色、premultiplied-alpha BOX与artlib painter；固定世界坐标到拟合网格倍率。站防不另加外描边。矩形峰值不等于两人并发池预算；不因超预算自动缩人物。
5. 原展示页开放八普通技及E/Q、自动播放、源图/拟合对照；空攻在舞台腾空，技能效果使用世界锚点。
6. 判定、伤害、取消、命中确认分支是设计字段，不冒充已接游戏。正式接入后另跑确定性/回滚/墙边/双人测试及真机观察。
