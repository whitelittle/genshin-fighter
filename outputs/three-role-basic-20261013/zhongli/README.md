## 本轮流程

1. 阅读仓库入口、最新工作流、美术标准、角色标准和尺度处理方案。
2. 核对已有25组及七组历史返修：复用前后走、跳跃、前后冲、蹲姿、防御、轻攻二、E/Q、空轻、投技/被投与受击稿；不把旧背景烘焙稿作为透明成品。
3. 新返修待机、站重、轻攻三、蹲重、空重、起身、胜利、败北。轻攻三/蹲重首轮粘连保留为失败历史，追加间距稿；蹲重第4姿缺枪尖追加单姿修复。轻攻一使用既有关键姿、此前恢复姿返修和精确复用持枪首姿结束。
4. 真alpha连通域提取，逐组登记不同版式；保留整张源图和逐姿ROI，禁止按统一网格误读相邻身体。单姿返修独立登记来源。
5. 身体逐姿等比缩放，以人工头部投影估计统一尺度；不用武器最大外框等高、不做非均匀拉伸。支撑点来自实际落地像素簇，浮空骨盆为初步引导。透视估计不等于头颈/腿链独立美术验收。
6. artlib预乘alpha BOX、共享重要像素加权OKLab调色板、离线painter精确还原；深棕黑一逻辑像素内轮廓，保护肤色与亮部。不附加装饰闪光或地面影子。功能岩脊/陨星独立图层。
7. 建立60Hz显示时间轴；攻击准备/有效/恢复与图片数量分开。E只有生成事件，无被动持续伤害；Q只有命中分支展示头像和陨星完整演出；投技双方锁位、释放、落地/倒地及起身连接，无额外特效。
8. 验证25组覆盖、帧数量/时长/来源、PNG解码、哈希和图元重建；打包并检查ZIP完整性，制作网页可下载的全轮素材索引。
