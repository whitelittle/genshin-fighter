# 双角色图元池与三段加载修复

## 真机反馈

匿名玩家反馈芙宁娜／绫华战斗掉帧，游玩较久更容易卡顿；启动时报第二池无法实例化，宽屏遮罩露边，芙宁娜待机转前走变小。最新明确要求只测这两位、允许增加加载时间、额外2000图元分到三次加载，并提供当前模板资源索引1073741845。截图中的账号信息不保留。

**待验证推断：**主动扩池及其常驻负担可能影响部分组合，但上述结果没有证明真机“越玩越卡”的全部原因。温度、GPU重叠绘制、原生模板子控件和其他关卡脚本尚无直接测量。

## 程序修复

- 战斗保留池16000；选人14672、VS15344、战斗16000，额外2000按672／672／656分布。各阶段仍每更新最多创建32。直接跳入战斗的测试入口没有前两个界面，需在战斗加载下补齐。
- 暂停低空闲主动预扩池，保留进场必需加载和耗尽时的应急补充；总上限20000。原生内存会因保留池加大而增加，不承诺提升FPS。
- 接回此前没有调用的离场回收入口。测试强制增加512，离场后按预算销毁，回到16000。六次菜单／战斗循环无新增；菜单轮换头像使占用在734／909／966间变化，未持续增长。
- 模板默认索引改为用户给出的1073741845；显式GF_IMAGE_TEMPLATE_INDEX参数仍优先。创建失败记录索引、容量、目标及创建数，立即停止运行，避免反复尝试。
- 全局根容器按当前画布尺寸设置，加载中也更新尺寸；永久底色、全屏遮罩、错误页使用实际画布。大招条幅改为画布宽度，头像矩形下沿裁切至228设计单位，保留原头部倍率；原素材不变。
- 芙宁娜前走参考帧轮廓70像素、待机80像素，原本均4.5倍。按最新缩小反馈，前走六帧统一乘80/70，脚底锚点随父变换保持，不按每帧武器包围盒伸缩。保留原取景镜头；原帧和页面不覆盖。此为新的运行显示修订，观感待玩家复测。
