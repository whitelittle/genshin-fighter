# 界面规范：格斗游戏版式 × 原神配色

这份规范写给改界面的人和 AI。核心一句话：**版式按 3A 格斗游戏（GGST、GBVS、SF6 一类）来做，配色和装饰用原神的。**
最常见的失败是做成"网页仪表盘"：圆角深色盒子、所有东西居中对称、每段文字都加描边、拿同一个星形当万能图标。下面的规则就是用来防这个的。

组件都在 `lua/gf_ui.lua`。实际效果可以运行 `python -X utf8 game/tests/shot.py gallery` 看设计样张。

## 1. 视觉语言

| 要素 | 规则 |
|---|---|
| 斜向 | 主斜角 `UI.SLANT = 12°`。大色块、分隔线、流光都沿这个角度倾斜。一个画面内斜向要一致（左侧面板用 `-UI.SLANT`）。选中条只倾斜 2° |
| 色块 | 用倾斜的 `UI.slab`，不用圆角盒子。色块要大，并且延伸出屏幕边缘 |
| 文字 | 白字直接压在深色色块或暗化的背景上，**不加描边**。只有压在图上、可读性不够时才加淡描边（alpha 不超过 90） |
| 字号层级 | 角色名 80–104，界面标题 50–54，菜单项 30–40，正文 18–22，英文小标 14–18（用 `UI.track` 拉开字距，配金色） |
| 幽灵大字 | 背景放一个巨大的英文词（字号 150–220，alpha 0.05–0.08），随选中项切换并滑入 |
| 标志性大字 | 游戏 logo 这类标志性标题做成图形（`tools/logo/logo.html` → `build_logo.py`），不要直接打字 |
| 图标 | 元素用 `UI.element` 或 `UI.badge`。四角星只用于星座装饰和胜场星，**不能当通用图标** |
| 装饰 | 原神金细线（`UI.GOLD`，宽 2–3）、菱形小点、`UI.constellation` 星座环、斜线纹理 `UI.stripes`（alpha 0.03） |
| 动态 | 画面上永远有东西在动：斜向流光、星座环慢转、选中条扫入、入场错落滑入。静止的画面看起来就是网页 |

## 2. 配色（`gf_ui.lua` 里的常量）

| 名称 | 值 | 用途 |
|---|---|---|
| `UI.NAVY` | 11,15,31 | 主色块（alpha 0.8–0.9） |
| `UI.NAVY2` | 22,28,52 | 卡片底 |
| `UI.CREAM` | 236,229,216 | 选中条、印章、按键键帽 |
| `UI.TEXT` | 37,42,60 | 奶油色底上的深色字 |
| `UI.GOLD` | 211,188,142 | 原神金：细线、英文小标、序号（**不要换成亮黄色**） |
| `UI.GOLD_HI` | 255,222,150 | 只用于奖励和星级 |
| `UI.ECOL[元素]` | 七元素色 | 角色相关的强调色、光晕、色块染色（用 `U.mix(ec, UI.NAVY, 0.55–0.78)` 压暗后再铺大面积） |

每个界面只选**一个强调色**（当前模式色或当前角色的元素色），不要彩虹配色。

## 3. 版式模板（新界面从这里挑一个）

1. **菜单型**（主菜单、暂停、设置、说明）：`UI.leftPanel` 放左侧斜面板，加 `UI.screenTitle`；左侧放 `UI.menu`；右侧大面积放角色、选中项的大标题或说明。参考 `gf_scene_menu.lua`、`gf_scene_options.lua`。
2. **对峙型**（选人、联机大厅、VS）：左右两侧各一块元素色斜面板，中间留出缝隙；名字放在顶部两侧，用大字号，一侧左对齐、一侧右对齐；中间放信息。参考 `gf_scene_select.lua`、`gf_scene_online.lua`、`gf_scene_vs.lua`。
3. **结果型**（结算）：一侧是角色大立绘配元素斜面板，另一侧是深色斜面板，上面放大标题、细线分隔的数据行和菜单。参考 `gf_scene_result.lua`。

## 4. 组件用法

```lua
local L = G.layer(app.layers.ui)          -- 每帧 L:begin() ... L:finish()，调用顺序就是绘制顺序
UI.leftPanel(L, W, H, k, accent, 1)       -- k = 入场进度 0..1
UI.screenTitle(L, W, H, '设置', UI.track('OPTIONS'), k)
UI.slab(L, x, y, w, h, UI.NAVY, 0.85, -UI.SLANT)
UI.badge(L, 'hydro', x, y, 60, a)         -- 元素徽记（圆底 + 细环）
UI.prompt(L, x, y, 'J', '确认', 1, 'ok')  -- 键帽提示；第 7 个参数是菜单动作，传了才能触屏点击
UI.menu(app, app.layers.ui, items, {x =, y =, w = 560, h = 76, gap = 12, size = 40, numbers = true, accent = col, onPick = fn})
```

- 数据行：左边灰色标签，右边白色数值，下面一条 `L:rect(..., 1, UI.WHITE, 0.14)` 的细线。不要用卡片。
- 状态印章（已准备、已确定）：奶油色 `UI.slab`，倾斜 ±8°，一端带元素色竖条。
- 名字块：英文名（金色，字距拉开）在上，大号中文名，元素徽记，一条元素色细线，下面是称号、元素和武器（灰色）。

## 5. 动效参数

| 场景 | 参数 |
|---|---|
| 面板滑入 | 0.3–0.5 秒，`outCubic`，从屏幕外 500px 处滑入 |
| 选中条扫入 | 9 帧，`outCubic`，宽度从 25% 扩到 100% |
| 列表入场 | 每行延迟 3 帧，14 帧滑入 160px |
| 大字冲击（VS、回合播报） | `outBack`，从 1.9–2.2 倍缩小到 1 倍，带残影和扫光 |
| 流光 | 8–12 条，宽 2–4，alpha 0.08–0.14，沿斜向循环，速度各不相同 |

## 6. 禁止事项（每条都出过问题）

- 圆角深色盒子装文字；三块一样大的面板并排；所有元素居中对称。
- 每段文字都加黑色描边。
- 亮黄色（255,214,120 一类）的细线和标题，看起来很廉价；细线用 `UI.GOLD`。
- 四角星当图标；用 emoji 或 `★` 之类的字符当图标。
- 选中条的倾斜方向和画面主斜线相反。
- 面板图层在菜单图层之后创建，把菜单盖住（先建面板，再建菜单）。
- 场景色块放进 `world` 图层，把角色盖住（色块放 `back`）。
- 一帧里构建两张高清立绘，或者在场景切换的那一帧同步释放整张背景。
