# 角色、动作、技能、特效统一标准（提案，未自动执行）

## 1. 角色母版

每个角色先做一张可读的母版和一套侧身对战方向，保留原 V2 的轮廓、锚点、比例和颜色层次。脚底是世界坐标锚点；图像坐标 y 向下，逻辑坐标 y 向上。渲染使用 `x = worldX + face*(px-anchorX)*u`、`y = worldY + (anchorY-py)*u`。浮空只改变视觉偏移，不能改变受击箱，除非动作卡明确声明。

## 2. 动作目录与帧

每个角色至少交付：待机、行走两帧、前后转身、冲刺、蹲下/蹲防、跳跃起跳/空中/落地、轻攻击 1/2/3、重击、蹲轻/蹲重、空轻/空重、站防/空防、受击/空受击/倒地/起身、E、Q、抓取、被投、胜利、失败。动作卡分别记录 startup、active、recovery、cancel、无敌窗口和关键帧。关键帧优先保证可读性；插帧必须经过设备门禁，不能用“图片数量”代替动作逻辑。

## 3. 碰撞与伤害

受击箱绑定身体意义区域，攻击箱绑定刀刃、手掌或技能前端；图像不自动生成碰撞。只在 active tick 检查命中，快速投射物使用连续扫掠盒防止穿透。每段多段伤害有独立事件 ID 和时间窗，伤害由逻辑帧决定，不由每张图片决定。大招命中确认后才进入短时专属镜头：背景切换、对手被击飞、数段攻击按时间出现；落空或防御不进入完整演出。

## 4. E/Q 与投技

草神 E 采用举手、短暂瞄准、绘制像素瞄准图快速扫过目标，再在命中点显示草元素反馈，禁止慢速锁定框和廉价地面绿柱作为主体。草神需要保留轻微浮空感。雷神 Q 采用命中确认后的背景/眼睛和连续斩击，保持原本几秒的视觉节奏。投技共用抓取条件：近身、可抓状态、非倒地/受击保护；抓到后锁定双方位置，执行起手、抓取、抬起、摆动、投出、落地和起身。兰那罗是抓取投掷的表现与助手，不能只播放粒子击退。

## 5. 特效与层级

背景、角色、前景和 UI 分层；Q 的角色切背景不可同时叠加两个重复背景。特效使用透明独立图元，记录发射 tick、持续 tick、最大并发数和回收时机。脚底地面保持连贯，草地摆动属于场景层，不能让整个战斗场景旋转。

## 6. 美术生成和后处理

提示词必须指定透明背景、单角色、完整四肢、动作阶段、面向、脚底锚点、像素网格、无裁切、无内置特效。先用原 V2 的 premultiplied-alpha BOX、重要像素加权 OKLab、共享调色板和分层 painter；再做去孤点并保护眼睛、武器和发饰。描边和内部对比度是可选后处理：只在质量提升且相同设备无性能回退时采用。原始关键帧和处理后关键帧都保留哈希。

## 7. 交付卡

每个动作必须有 manifest：动作 ID、源图哈希、帧顺序、逻辑 tick、startup/active/recovery、攻击/受击盒、锚点、缩放、特效事件、调色板、用户验收状态。角色完成后再进入下一个角色。
