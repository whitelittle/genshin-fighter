# 下一版本UI与AI方案

更新：2026-10-03。同日后续已生成两角色头像、开始/选人/战斗/结算 UI 与动作候选，见[交付说明](../outputs/duel-vnext/使用说明与节点改动.md)。模拟器通过，真机未验收；新 AI 尚未实现。以下建议仍需按实际候选与用户后续设计修订，不能当作所有功能均已完成。

最新实施顺序更新：用户明确先完成刻晴/迪卢克动作与双人流程，用户提供动作设计、Codex接入；单人AI后续再做。更多角色名单及动作交接见[双人下一版实施与动作交接](双人下一版实施与动作交接.md)。本文AI建议保留为后续范围，不表示当前双人优先任务已经包含AI交付。

## 已确定的方向

维持2D单角色1对1，采用三局两胜。用户先讨论三人接力，随后明确取消本轮接力，改为ROUND ONE、ROUND TWO等回合提示；三人接力留作后续补充包。不要为本版继续制作三人阵容、换人或两个队员头像。

选人布局采用下方头像列表，上方左右显示双方当前预选角色的站立动画。当前角色为刻晴、迪卢克；不因先前讨论三人阵容而假定已授权新增第三名角色。

当前保留完整人物造型与素材精度，更多更细的动作是后续方向；UI和动画需要同时考虑手机图元成本。

开始页装饰与演出先以静态和少量容器动画为主。选人页仅播放两个当前预选角色，不同时播放全部角色；隐藏姿势仍可能占常驻资源。

头像建议统一构图的半身像，突出脸、发型与肩部，而非缩小全身精灵。选人使用大尺寸，同一资产可供对战HUD复用。原先提出的像素街机配紫/橙红是风格建议，未完成用户视觉验收；长期参考仍包括DNF Duel，不将其误记为必须彻底换风格。

## 镜像角色与配色

建议每名角色两套配色，镜像对战自动区分。主要改变衣服主色、阴影、饰边和部分武器装饰，保护肤色及识别特征。两套配色共享姿势几何，不复制整套动画图元。

下一步素材结构应保存语义颜色槽：衣服主色/阴影、饰边、肤色、头发、武器等。当前原始RGBA数值并没有完整语义分组，不能假设全局替换某个颜色只会改变衣服。调色表方案与具体替代色仍待制作、对照和验收。

血条靠屏幕外侧放当前角色头像，尽量利用原HUD高度；不增加中央大背景板。三人接力已延期，两个队员头像和死亡灰化属于后续包。最高跳跃点、武器上挑及不同手机宽高比需检查遮挡。

## AI范围

已有基础角色AI，不等于下列完整AI已经实现。下一版建议先完善普通难度和基础训练陪练，再调简单/困难。

- 刻晴偏接近、距离调整、快攻和短连段；迪卢克偏剑长控制、空挥惩罚和重击。
- 距离与场上状态决策；命中后才选择衔接，被防住时可能停手。
- 起身、防御、对空与接近倒地对手；遵守收招、硬直、资源及合法取消。
- 难度通过反应时间、失误率、防御判断和连段成功率调节，优先保持与玩家相同伤害和规则。
- 训练陪练：站立、持续防御、随机防御、反复跳跃；不必把所有训练项塞进普通对战AI。
- 通过玩家共用输入接口操作，不直接改角色状态或跳过招式限制。若随机决策涉及回放/确定性，保存随机种子和AI状态或记录AI输入；不在回滚重算时产生新的随机决策。

进攻/防守/均衡风格、随玩家水平调整、学习玩家习惯可作为扩展；本版未承诺机器学习、在线服务或训练模型。

参考核查于本次会话，只能支持以下具体设计借鉴，不能据此声称掌握商业游戏内部AI算法：

- [铁拳8官方1.13说明](https://www.bandainamcoent.com/news/tekken-8-patch-notes-v1-13)：Ghost对战包含进攻、防守、均衡风格。
- [罪恶装备Strive官方模式说明](https://www.guiltygear.com/ggst/en/howto/mode/)：CPU相关单人模式与针对特定情境的Training练习分开。

## 必须同步设计的技术规则

现有Lua在P2获得席位后自动发Join；“人齐”很快进入战斗。正式UI需要改为席位分配→选角/设置→双方准备→服务端开战，不能只画按钮而继续自动Join。

建议明确状态：TITLE、SELECT、READY、ROUND_INTRO、FIGHT、ROUND_END、MATCH_END。这是规划，不是现有状态枚举。角色、配色、地图、回合开始与重赛需要双方一致。单人菜单可以暂停；双人菜单默认不暂停战斗，退出与断线要明确表现。共享暂停需协议支持。

后续三人接力作为独立规则配置，避免把角色队列耦合进当前单角色回合逻辑。首版不要提前创建三名常驻角色。

## 下一版验收建议

先完成灰盒流程和输入锁定，再验收头像/菜单视觉；双方准备与取消、镜像配色、三局两胜、平局、再战与返回均要测试。手机同时触控及最高跳跃遮挡要真机检查。AI需验证能犯错、不会非法抢招或完美读键，以及不同角色确有打法差异。正式演出不应触发每帧重绘大量图元。
