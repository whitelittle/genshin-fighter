# 第一版双人测试版

2026-10-03 最新用户要求；本文优先于此前仅两角色候选范围。旧文件、旧包全部保留。

## 交付顺序

1. 无选人、固定刻晴对迪卢克复测包：已导出到千星，`gpt_20261003_110236_无选人_双人战斗复测.gia`。这是握手与输入复测包，不是完整测试版。
2. 完整候选：开始、同步选人、双方确认、各自完成加载后开战、三局两胜、结算、双方再战或返回。需要用户按新的节点说明接线。

## 设计要求

- 菜单只加载缩小的待机预览与头像。战斗前加载当前两名角色各自最大姿势图元池；仅迪卢克加载火鸟池。退出释放运行时实例，同角色下一回合复用。未来接力采用下一位上场前黑屏加载，本版仍是单角色三局两胜。
- 手机按小时间预算创建/释放；加载条按真实创建进度更新，派蒙独立换帧。隐藏与卸载严格区分。
- PC 隐藏触屏摇杆与战斗按钮；手机保留方向、跳、轻、重、防、E、Q。H 打开指令表，不冻结联机模拟。删除战斗页大段说明。
- 清晰背景、地面统一光照与配色；原生分层场景控制图元数量。改进头像、血条、能量、胜场标记、选人状态、触控按钮和结算。
- 新角色：凯亚、琴、可莉、丽莎、甘雨、烟绯、魈、胡桃、岩盔丘丘王。以原作 A/E/Q 为参考，改编为格斗规则，必杀一次判定；关键姿势候选与细致动画验收分开。
- 选人角色、准备、场景、轮次与加载完成同步；结算再战需双方确认，返回退出传达给对方；过期包不得开启新战斗。

## 证据状态

**真机观察**：用户反馈旧版手机加载极慢，PC 也不快；此前席位、开战、输入转发曾成功，攻击时可能出现暂停预测。没有本版真机测量。

**模拟器验证**：无选人复测包双客户端启动通过，PC 触控控件隐藏。完整候选各项验证记录随交付生成，不能据此承诺手机帧率。

**待验证推断**：降低菜单和战斗常驻池、减少创建属性写入有望缩短加载；实际实例化成本、模板索引、手机帧耗时仍需设备测试。输入网络断续与图元换帧耗时需分别定位。

## 验收清单

本轮已生成完整候选 `gpt_20261003_120005_A_第一版双人测试.gia`，并放入用户千星导出目录。11名角色、分段创建与紧凑姿势展开、选人同步、H、PC/手机区别、三局两胜、双方再战和返回流程均已有实现。模拟器报告在 `outputs/test-v1/*verification.json`。官方节点需按说明手动接线；真机性能与细致动画不作为已通过项。

- 双客户端不同选人、同角色、取消准备、迟到消息、加载先后不同时不提前开战。
- PC 无摇杆按钮，手机布局不遮角色；H 与手机指令表入口可用。
- 每个角色可进入、轻重/E/Q、受击、防御、蹲伏、跳跃、倒地；角色名与素材对应。
- 结算再战不单方面启动；返回后池释放，可再次进入；旧 Epoch 输入被拒绝。
- 导出往返脚本映射正确；提供实际千星路径及节点图参数说明。
- 标明尚未完成的细致中间帧、角色平衡和真机性能，不能将候选标为全部验收通过。
