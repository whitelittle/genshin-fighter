# 五角色动作样板：提示词、流程与制作标准

日期：2026-10-03。状态：项目设计候选，第一轮关键姿势已生成并目视检查；完整逐帧动画未制作，正式战斗未更改，千星真机未验收。样板入口 `outputs/motion-samples-v1/index.html`，实际发送的提示词在同目录 `prompts.json`，缺陷清单为 `review.json`。技术通用流程另放 `docs/share/动画素材验收流程.md`。

## 五个样板及用途

|角色|先验证动作|重点|后续必杀意图|
|---|---|---|---|
|刻晴|低重心短剑横切|握柄、剑路、瞬移落点、短促收招|首击命中后剑影演出，终斩；防住/打空不锁人|
|迪卢克|双手大剑斜劈|后脚加载、前脚支撑、重心跟进、刹住刀势|火鸟作为命中演出意象；E三段仍区分剑路|
|那维莱特|聚水、前伸施法、收手|施法手锚点、法杖、稳定持续姿势|本轮统一方案一候选：首束接触后进入定长洪流演出；旧自由喷水探针保留比较|
|纳西妲|胸前聚能、向前施放、收回|儿童原有比例、侧向轮廓、手势|不做长期领域；智慧殿堂意象用于命中后的短暂空间演出|
|神里绫华|握鞘蓄力、拔刀横扫、收刀|刀鞘握持、完整剑身、裙摆和支撑脚|冰风意象用于命中演出，场上演员仍为同视角动作|

用户最新建议领域改为动画后改变攻击形态，或统一为方案一。本轮采用统一方案一作为优先验证候选；状态型增益暂缓，不将此选择写成所有未来角色的永久限制。上述是设计意图，当前旧探针的领域、持续攻击模型尚未按此替换。

## 必杀流程标准

输入与能量条件满足 → 起手/短暂开场提示 → 首击真实判定 → 分支。命中才进入成对攻击/受击演出；防住用防御反馈并收招；打空用空挥收招。演出结尾的终击结算主要伤害，再进入受击/倒地与施放者收招。是否允许特定投技绕过防御须另立规则，不能默认为所有必杀都必中。

演出中的多条刀光不自动等于多次伤害。记录一次命中/伤害事件编号，避免回滚重播再次扣血。演出帧、双方锁定状态、起始落点、朝向、动作ID、已结算标记归入同步状态；不能依赖本地图片加载完成、屏幕FPS、动画结束回调结算。视觉卡顿时逻辑不延长演出。KO提示在预定终击后出现；本轮未实现这套正式联机演出。

## 提示词结构

完整实际提示词保存为 JSON，不靠会话复原。共用部分：透明背景；当前像素角色身份/服饰参考；固定横版侧向镜头、统一朝右；全身完整、脚底基准一致；不画正面立绘、俯仰镜头、背景、文字；不加遮挡人体的特效；禁止武器重复、离手、额外肢体。角色部分写清动作目的、前后脚、髋肩关系、握持位置、武器轨迹及收势。

本轮四姿势板只用于比较设计，不能直接均分切图。已发现武器侵入相邻格，后续运行时母版采用“一张图一个姿势”，每帧引用通过的待机母版及相邻关键姿势，锁定服饰、镜头、尺寸与持械。补帧提示必须指定连接哪两姿势和哪条运动轨迹，不使用笼统“做流畅动画”。镜像先核查持械、服装与发射锚点，不能假定镜像永远正确。

## 制作流程与门槛

1. 查原作视频和本地格斗观察记录，写动作意图与可见证据；区分借鉴、横版改编和自创部分。
2. 锁定待机母版、角色尺度、脚底、镜头、服饰与武器。母版未通过不能连做十几帧。
3. 做无特效起手、释放、收势关键姿势；检查重心、握持、前后关系和独立轮廓。问题帧返修，不用光效遮问题。
4. 通过关键姿势后补中间帧。候选数量：短剑6–8张、重剑8–10张、施法起手/释放/收势6–8张，持续施法另做3–4张循环；仅为起点，按实际动作删补。最快挥击可跨幅，不平均插值拖慢。
5. 特效独立制作：预备、释放、飞行/持续、命中、防御、残留；只有实际命中才显示命中爆光。绑定手/武器/地面锚点，特效外缘与判定分别标明。
6. 到实际游戏尺度进行网格、有效色、修边和矩形拟合；保护头饰、握柄和外轮廓。记录每帧矩形及共享峰值，不能以统一数量上限破坏角色。
7. 动作探针检查正反向、四分之一速度、无特效、黑白轮廓、命中/防住/空挥、近中远距离；保存帧序、帧持续、锚点和事件表。
8. 通过后才进入正式战斗接入和GIA候选；补显示帧不自动改60Hz逻辑的起手、有效、收招和硬直。联机事件再做重复、回滚、KO与退出检查。

## 制作标准

- 同角色各帧骨架尺度与服饰一致；成人以既有约232世界单位为显示基准，儿童保持既有相对身高。图片分辨率与世界尺度不是一回事。
- 有地面支撑的关键帧脚底对齐；跳跃/浮空单独记录逻辑升降，不把裁切漂移当动作。
- 无裁头、裁刀、粘连相邻姿势；所有帧真实透明，不保留背景光晕或整张半透明薄雾。需检查alpha分布，不能仅看黑底预览。
- 起手、出手、收招仅看人物也能区分；末帧可自然回待机。武器抓握稳定，肘肩/髋膝不反折。
- 刀光与剑尖路径一致；束流从施法端产生；命中/防御反馈位置与接触事件一致。
- 演出不依靠巨大立绘替代演员帧，短暂独立插画若后续保留也不改变场上动作标准。
- 负载验收区分帧数据总量、共享池峰值、图片/容器控件、可见/常驻、换帧写入与半透明重叠。只加载当前出战素材；池回收与实际销毁分别记录。没有真机测量不声称手机性能通过。

## 第一轮验收结论

五张首轮板均为概念候选，未通过运行时帧验收。刻晴武器跨格，绫华释放更像直刺；两者需按剑路单帧重做。迪卢克可读重心和收势，但握柄、完整剑身和缩至游戏尺度需再验。那维莱特方向已改善，前伸施法可用作动作参考，发射端和法杖连续性尚待逐帧核查。纳西妲额外返修一次，仍有光晕与偏正面姿势，返修未通过，不接入运行时。

所有原图及返修保留；生成使用内置 imagegen，以项目既有像素待机参考，不覆盖原素材。`image-audit.json` 保存尺寸和alpha计数，这不是像素或真机验收报告。
