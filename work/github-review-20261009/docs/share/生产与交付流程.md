# 生产与交付流程

1. 明确本次改动和当前基线。保留原文件，写独立候选；不扫描与任务无关的个人文件，不将教程写成接收项目的全局 AI 指令。
2. 收集有效参考，记录来源、用途与授权边界。原始图、处理图、拟合帧表、最终包分层保存；素材来源可追溯不代表获得再分发授权。
3. 做尺度、透明背景、降色、保护修边、锚点和矩形拟合。检查完整轮廓与小尺寸头像；仅通过代码检查不够，需要看处理图。
4. 写入状态映射和战斗事件，明确代用姿势。动画显示与战斗逻辑分开；视觉少画帧不能漏掉命中、发射或声音事件。
5. 压缩并逐帧往返校验；生成加载配方和差量绘制。记录图元峰值、数据量、常驻策略以及超界行为。
6. 本地模拟：初始化、选择/撤回/锁定、单方未准备、换场、结算、重赛、退出；抽样技能与回滚；手机宽屏及窄屏布局。改变联机/战斗规则才扩大相应回归，纯文案只查文本与布局。
7. 导出服务器模板与客户端图元模板，分别校验；重导入确认脚本路径和内容一致。记录模板容器索引、挂载容器、子图片名称和节点信号完整参数。
8. 生成版本清单、文件大小、哈希、安装步骤、已验证项和未验证项。使用时间戳名称，避免覆盖原交付。
9. 官方编辑器导入并真机核验。记录设备、加载时间、帧率/卡顿、双方联机表现，失败时回到对应层排查。

## 证据记录

每项结论标为设计决定、构建测量、模拟器验证、用户真机观察或待验证推断。保留验证对象的版本/哈希，不能把上一包验证直接当作新包验收。模拟器自动战斗或强制 KO 是测试夹具，不属于正式游戏规则。

## 交付最低内容

有效素材索引、当前构建入口、数据格式说明、验证报告、安装说明、节点协议、文件清单。历史文件留作对照，不要求学习者阅读全部聊天记录或临时脚本。
