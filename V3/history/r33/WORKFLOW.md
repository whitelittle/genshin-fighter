# 工作流与验收门禁

1. 冻结稳定基线 SHA，复制到独立工作区；不从未发布的 WIP 或错误包回滚。
2. 先写角色动作卡和碰撞卡，再制作一张母版、一个 E、一个 Q 和一个投技预览。
3. 逻辑先行：输入、状态、命中、伤害、投技、早死清理和联机同步通过脚本测试。
4. 美术离线构建：原 V2 painter、共享调色板、透明边缘处理；生产包只放已验收素材。
5. 设备门禁：同一设备、同一场景、同一输入脚本，对照原始关键帧、后处理帧、插帧帧。记录平均 dt、P95/P99、慢帧数、内存、图元创建数和每帧写入估计。当前没有用户批准的固定 FPS 阈值，先以“不低于基线且视觉收益明确”为准。
6. 通过门禁后才合并 Lua/GIA；GIA 只替换已核对脚本，保留模板和 UI。
7. 完整回归：进入游戏、选人、VS、单人、联机握手、战斗、结算、再来一次、重选、两角色互打、墙角、空中、倒地、投技和动态池回收。
8. 一次完成一个角色，统一标准通过后再扩展阵容。所有中间研究留在归档区，不能自动进入稳定包。
