# 本地评论观察

已针对指定B站视频和米游社关卡制作本机查看页。启动入口为项目根目录 `启动评论观察.ps1`；地址 `http://127.0.0.1:8807/`。只监听本机，不发布到外网。

## 每小时更新

本对话的小时自动化使用已登录的Codex浏览器读取评论DOM，通过 `monitor.py --ingest` 保存匿名正文。电脑与Codex须运行，B站须保持可读取评论的登录状态。登录失效、网络/页面变化时保留旧数据并标明失败；不保证关机期间采集或平台全部评论可见。

已创建并启用本对话自动化“每小时采集玩家评论”，标识 `automation`。任务负责调度，Python服务负责存储及显示；无需两份定时器同时请求原站。

当前采集器是“浏览器页面采集＋Python匿名存储”，不是完全脱离Codex的后台网络爬虫：本批实际验证B站公开接口返回空列表（页面有评论），米游社直接请求超时。`--refresh` 保留为有限公开接口诊断/候选入口，未验证能独立抓取两站完整内容，不能用其失败结果覆盖页面采集。

查看页每30秒只读本地JSON，不请求原站。每小时任务才请求原站。按钮“请求采集”登记下一小时任务处理；“刷新页面”立即显示本地最新结果。暂停更新可暂停本对话自动化；关闭查看页不影响已登记任务。

## 内容和隐私

- 只持久保存正文、来源站点、采集时间、页面覆盖说明；作者统一匿名。采集时先去除@回复对象，Python再遮盖账号标签、联系方式及个人环境路径。
- 不读取或导出浏览器cookies、密码、账号数据库，不保存个人主页及作者ID。评论正文仍按不可信文本展示，使用 `textContent`，不会执行其中HTML。
- 相同规范化文本合并并保留来源；不按身份计数，不把条目数当人数，不根据部分列表判断评论已删除。
- 主题是关键词初筛，不是语义判断、复现结论或已批准设计；精细理解仍看匿名反馈文档。
- 历史整理摘要是之前文档的转述，明确标记，不冒充新采集正文。数据位于本目录 `data/`，已排除Git。

## 手动维护

在项目根目录运行：

```powershell
python work/comment-monitor/monitor.py --serve --port 8807
python work/comment-monitor/monitor.py --ingest bilibili --input work/comment-monitor/data/capture-bilibili.json
python work/comment-monitor/monitor.py --ingest miyoushe --input work/comment-monitor/data/capture-miyoushe.json
python work/comment-monitor/monitor.py --status
python -m unittest discover -s work/comment-monitor -p test_monitor.py
```

页面DOM只读提取函数分别为 `capture-bilibili.js`、`capture-miyoushe.js`。通过受支持浏览器工具执行，而非自行连接调试端口或读取隐藏状态。B站只能收集当前加载主评论和已展开回复；下一页须由浏览器正常点击再采集，导入会自动合并。米游社若出现“展开”先展开正文，不点击触发客户端下载的评价/回复入口。

状态应如实写覆盖范围：列表未到底、部分回复未展开就标为部分；DOM选择器返回空值不能登记成功。默认每来源最多20次页面动作，每次小时任务不做无限重试，不操作评论发送、点赞、关注、下载安装或验证码。
