# 草神高清第一帧矢量算法研究与实测

## 目标与表示范围

用户目标为更精确、同时减少图形，并能以千星基础图元导出GIA。SVG曲线路径和千星基础图元必须分别计数。本文保留本次失败对照，不能将其称为原生低图元优化完成。

参考固定使用已选高清第一帧裁切251×462，不读取已拟合的像素帧，不缩小输入。颜色误差的参考将源图alpha>=48归为不透明，其余透明；合成白底后在主体范围统计RGB平均绝对误差。以resvg实际渲染SVG至3倍，再缩回参考尺寸。指标不能替代五官和线条的美术评价。

## 已查算法

- [VTracer官方实现](https://github.com/visioncortex/vtracer)：分层色块追踪；当前主分支文档还提供共享边界cutout、分水岭区域合并、容差内曲线简化。实测环境安装到的是Python 0.6.15，只测其stacked模式，没有冒称测过主分支1.0新增能力。
- [Potrace原始算法](https://potrace.sourceforge.net/potrace.pdf)：最优多边形、角点检测、贝塞尔平滑与相邻曲线合并。适合轮廓和二值线稿，不直接解决彩色分层及千星图元字典约束。
- [DiffVG论文和官方实现](https://people.csail.mit.edu/tzumao/diffvg/)：以实际渲染误差优化几何、颜色、线宽等参数。只优化既有表示，不自动保证形状数量减少；用于本项目时需要限制可用形状、添加数量约束，并核对真实GIA的变换能力。
- [LIVE原始论文项目](https://ma-xu.github.io/LIVE/)：分层逐步添加闭合贝塞尔路径，优化拓扑和图像误差。紧凑SVG路径不等于紧凑千星图元。
- [分割引导的渐变矢量化论文](https://arxiv.org/abs/2408.15741)：以渐变感知分割和径向渐变减少纯色阴影碎片。对SVG适用；千星GIA当前接口未核验支持相同渐变，不能直接采用为游戏交付。

旧报告的48色9,879轮廓、18色1,379轮廓未包含连续底层的6条轮廓；实际SVG全部计数应为9,885与1,385。本表统计实际SVG。VTracer减少很多几何，但尚未比旧48色更精确，不能宣称同时实现两个目标。旧补线版误差显著增大，也不能继续作为精度提升基线。

## GIA转换试验

GIA导出接口支持静态图片ID、颜色、尺寸、Z旋转和填充进度，没有任意SVG贝塞尔路径槽位。本次将18色SVG闭合轮廓按0.35参考像素容差离散为几何边界，再带孔三角剖分，每个一般三角形沿最长边高拆成两个直角三角形，以100003基础三角形横向左侧50%填充表示。未转为像素矩形。

结果52,276个原生三角形图片，GIA约45 MB，明显不符合低图元目标。SVG同色描边没有完整转换；独立图元抗锯齿接缝通过微小几何重叠试验处理。文件结构、回读后的图片ID/填充参数、模拟器启动检查通过，不表示美术或真机验收通过。

## 应采用的下一轮方案（设计，未实装）

直接以千星支持的基础图元作为拟合字典，使用区域优先初始化，再根据渲染误差选择新增图元；每轮共同调整已有图元的尺寸、位置、旋转、颜色和层序。固定图元预算；五官、手脚、外轮廓提高权重；大面积近色阴影允许合并。尝试删除或合并图元后必须重新渲染验证，保留误差与数量之间的候选曲线。

这种方式能控制实际GIA图元数量，但达到约1,300个图元时能否保住本图细节仍需实测。不能先制作大量任意曲线再以三角形拆分称为少图元拟合。
