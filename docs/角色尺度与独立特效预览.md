# 角色尺度与独立特效预览

更新2026-10-03。用户最新修订：纳西妲适度整体放大供查看，不能单独拉高身体。当前默认显示120%，支持原尺寸与80%–140%连续等比调整。源帧与原身高150不改，脚底锚点保持。放大后展示高度180，是探针预览，不是正式碰撞体规格。上下段线只是视觉参考，不冒充真实攻击判定。

独立预览：新增60逻辑帧特效时间轴、单独播放/暂停/重播、只显示特效、主体/接触分层。绑定手部、胸前、脚底、对手中心或固定场地点；支持本地朝向镜像、横纵偏移、缩放和导出绑定配置。手部位置目前按姿势估计，尚非逐帧美术标定。魔法弹、短斩击、印记、地面波纹是紧凑结构试验，具体角色技能特效待讨论；旧特效可切换比较。角色与特效分别播放、分别存储，不改变伤害和联网数据。

参考状态：已打开并目视DNF Online官方[魔皇演示与技能页](https://www.dfoneople.com/news/updates/2194/Neo:-Elemental-Bomber)局部大范围爆发画面，该游戏不是用户本次重点的一对一DNF Duel。DNF Duel官方[小魔女演示](https://www.youtube.com/watch?v=dAbrqLes3dQ)已定位，但嵌入播放器报错、公开播放页操作超时，不能记作已完整观察。下一次研究必须优先这个一对一样本与[官方角色页](https://dd.nexon.com/en/fighters/7)，不能用DNF Online代替。

设计推论（待讨论）：预备小光源绑定施法手；弹体出手后有自己的轨迹和寿命；接触闪光区分命中/防住/空放；地面作用用脚底区域表达；装饰光不等于伤害范围。不为了大招规模直接把普通特效拉长至半屏。当前试验由既有格斗研究与数据结构推导，不冒称DNF Duel完整抽帧所得。

本地检查：360次Canvas绘制与绑定点等比缩放验证通过，报告outputs/motion-production/effect-lab-verification.json。浏览器已查看纳西妲120%与手部独立魔法弹。真机未验证、正式战斗未改变。第一组凯亚48帧制作与说明见outputs/motion-group1/README.md。
