# 风起地像素母版拟合实验

2026-10-04；设计候选，未接入正式 GIA，真机未测。

内置 imagegen 生成像素风母版，再用现有本地静态工具的 sample → colorProcess → fit 转换。原图保存 source.png；生成提示词保存生成提示词.txt。完整英文提示词保存 prompt.txt。

生成输出并非严格低分辨率或固定调色板，因此本地转换仍是必需步骤。所有 fitted.png 由输出矩形逐一绘制重建，与合色后网格逐像素验证一致；矩形数据见各档 rectangles.json，成本见 report.json。

相同240×135、32色、区域平均、容差3：旧图13,133个矩形，新图8,847个，减少32.6%。不同构图与母版共同影响结果，不将该比例泛化为所有像素画的固定收益。

320×180、32色、最近邻：15,296个矩形；480×270：29,553个矩形。页面附独立新版绫华尺度对照，不计入场景矩形数。约控件为现有一容器加一图片模板的两倍估算。

仅生成新的候选目录，不删除、覆盖旧素材，不提高正式包精度。
