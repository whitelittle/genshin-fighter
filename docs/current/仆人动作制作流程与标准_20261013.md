# 阿蕾奇诺动作制作流程与标准

2026-10-13。匿名玩家评价当前仆人动作做得很好，并询问流程、标准和工具。本文核对实际制作文件后整理方法，属于经验记录，不启动新的制作或开发。

## 实际流程

1. **先设计动作与固定母版。** 读取本地原作技能资料和立绘，写动作设计卡；首版身体过长后重新绘制正常成年比例，不用横压纵拉修体型。固定发型、衣服、配色、侧向三分之四视角与人体尺度。
2. **按动作阶段生成真正不同的姿势。** 先待机、步态和代表攻击，确认后逐组扩展。前走拆成接触、承重、经过等六相；攻击拆预备、发力、命中和收势。首尾明确接回待机，保持与复用帧如实标记。
3. **逐对象提取与修源图。** 用真实身体核心、枪杆、镰刃的源坐标确认归属，不按等宽格机械切图。保留发梢、细枪杆和原 RGBA，剔除背景残片；发现杆轴弯曲或邻姿头部混入时修源图／提取方法，不用拟合掩盖错误。
4. **等比定尺度与锚点，再降色拟合。** 人体单位按母版与世界尺度板校准，地面锚点按实际鞋底，不按更低的刀尖。空中姿用虚拟支撑，起落与空攻保持同一 root。身体采用统一 19 色调色板，输出矩形集合，并重建 PNG 做逐像素比较。
5. **分层编排演出和双人动作。** 身体与持握武器按姿势处理，斩光、火翼、标记、命中反馈和立绘独立。E 光点绑定手掌，标记绑定对手。Q 区分完整命中与短收招分支；投技按成人和低位对手适配仆人自身接触姿势，保留原对手素材。
6. **反复播放、反馈返修，再接游戏。** 查看源图／拟合、镜像、首尾衔接、跳跃→空攻→落地、投／被投与倒地起身。生成帧序列、持续拍数、锚点与事件数据，再接入角色 provider、动作规则和战斗显示；独立播放器、模拟器与真机分别验证。

## 采用的标准

- **人体稳定：** 同角色头身、躯干、四肢与衣服尺度一致；自然蹲伏、扭转和伸展保留，不以剪影外框等高为标准。
- **动作成立：** 看得到支撑、重心和发力；走路有经过姿，不能用平移待机代替步态。攻击有起手、有效姿和恢复，枪杆／镰刃方向、长度、握点与手一致。
- **连接连续：** 重点看首尾帧、循环接缝、鞋底与 root；空攻继承空中根坐标，倒地／起身方向一致，镜像整体翻转。
- **提取正确：** 不裁头发、衣摆和武器，不混入邻姿，不把背景光晕留作身体；身体／武器归属不能只靠轮廓框猜测。
- **表现与逻辑分开：** 特效不决定人体大小，不因为斩光更长就扩大伤害；Q 命中、空挥、防御和投技接触按明确时间线处理。
- **质量和成本同时检查：** 矩形重建必须与拟合目标逐像素一致；同屏身体、特效、双缓冲、隐藏池、换帧和颜色改写分别计数。无损数据检查不代替动作观感判断。

这些是本批实际使用的制作与检查方法。初始素材交付为 **25 组、138 主序列显示状态、120 个唯一身体图（含变体）、8 个特效**；显示状态包含保持和复用，不称 138 张独立原画。身体峰值 1385、单特效峰值 641 矩形是负载记录，不是通用限额。2026-10-13 后已完成正式运行接入和模拟器检查；较早 `current-status.json` 的“未接入”是历史制作状态。最新动作观感评价与程序／设备性能分别记录。

## 实际工具

|环节|工具／文件|作用|
|---|---|---|
|复杂姿势绘制、返修|内置 `image_gen`；`source/`、`prompts/`|基于母版和动作说明生成／编辑位图，保留完整提示词和失败版本|
|提取、归属、等比校准|Python、Pillow、NumPy；`work/arlecchino_fit_initial.py`、`source-calibration.json`|透明主体、细杆／镰刃归属、脚底及源单位校准|
|降色与矩形拟合|项目 `game/tools/artlib.py` 和 `work/clorinde_assets.py` 的 `canonical_fit`|统一调色板、矩形表示、目标图与矩形重建核验；复用方法，不复用别人的角色数据|
|动作设计／时间线|`动作设计卡.json`、`actions.json`、`effects.json`、`pairing-profiles.json`|姿势顺序、持续拍数、源锚点、效果与双人接触编排|
|逐帧和连续检查|HTML／JavaScript 播放器 `player.html`、`player-v2.js`，浏览器与世界尺度对照板|源图／拟合切换、镜像、时间轴、分支及配对检查|
|自动质量核验|`work/check_arlecchino_ownership.py`、`work/check_arlecchino_full_delivery.py`|对象归属重叠、RGBA 保留、矩形重建、交付完整性与哈希|
|游戏接入与验证|Lua 5.3；`runtime/tools/export_dual_delivery.py`；离线原生控件近似器、回滚及图元测试|素材与规则接入，检查流程、时序、绘制峰值和同步|

核心是“固定母版与尺度→真实分阶段姿势→逐对象修图→校准与分层→逐帧及连接检查→游戏接入”的闭环。生成工具负责提供图像候选，动作质量来自设计、校准、播放检查和返修。
