# 刻晴对迪卢克格斗原型 v0.1

这是独立编写的千星客户端 Lua 原型，玩家控制刻晴，迪卢克为本地 AI。人物为程序绘制的色块示意，未采用旧纯侧身迪卢克作为正式母版，也未修改用户认可的刻晴高清图。此版本验证玩法，不宣称正式角色美术完成。

## 试玩

运行项目根目录 `启动格斗原型.ps1`，打开 http://127.0.0.1:4192/ 。独立端口与项目目录，不覆盖嘟嘟可大冒险服务及工程。

| 按键 | 行为 |
|---|---|
| A / D | 左右移动 |
| Space | 跳跃 |
| J | 快剑 |
| K | 重剑 |
| 按住 L | 地面防御 |
| R / RESET | 重开比赛 |

页面同时提供触控方向、跳跃、攻击、重剑和防御按钮。移动与防御按钮为按住模式。触控多指体验未真机验证。

规则：各100血；回合60秒，超时以剩余血量判胜；平局不加胜场；先获2个胜场赢得比赛。攻击有前摇、有效和恢复阶段，每次招式至多命中一次；防御承受少量削血。高度差超过75时地面攻击不命中，地面角色以50宽推挤框分开。

快剑/重剑通过 Down 事件放入短输入缓冲；恢复后若缓冲仍有效可接下一招。尚未实现正式连段表、搓招识别、投技、蹲防、弹道、多人同步或回滚。

战斗内部以1/60秒固定步长推进，模拟器文档所述的外部30 FPS会每帧推进两步。该方案用于统一规则计时，不意味着真机画面60 FPS。单次输入超过0.1秒按0.1秒处理，长卡顿时会放慢模拟时间，未做网络时间追赶。

## 千星资产

- `gpt_fighter_v0.1.gia`：整合包，包含UI和客户端Lua挂载数据，已重新导入本地模拟器检查。
- `fighter.save.json`：完整可编辑工程。
- `fighter.lua`：客户端源码，挂载到 `FighterDemo` 根容器；采用图元100001，无图片外部文件、动态实例化或自定义模板索引。
- `verification.json`：验证范围。已检查实际GIA导入、输入、移动抬起、跳跃落地、前摇、空挥、单次判伤、防御削血、空中高度、AI运行、超时/平局/比赛胜利和重开。

导入官方编辑器后核对根容器的脚本挂载和输入绑定；单独导入UI时需另行导入Lua并挂载。当前只在本地模拟器验证，千星真机导入、键鼠事件消费、触控手感和性能均待核验。
