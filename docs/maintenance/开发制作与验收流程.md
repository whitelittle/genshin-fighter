# 开发、制作与验收流程

2026-10-18。

1. 阅读根入口和相关 AGENTS，核对最新用户决定、有效候选哈希、真实加载入口与未完成项。先看页面实际消费的数据，不凭文件名找“最新”。
2. 先复现问题并存输入、状态、显示姿势和设备节奏。明确修规则、输入、提取还是显示；旧反馈无法复现时保留不确定性。
3. 制作前写动作设计卡，锁母版、人体单位、根点、阶段、技能意图。用户给动作概念，实现补字段，不要求用户手填技术表。
4. 一组动作先走通：生成/修图→完整轮廓提取→统一尺度和降色→矩形拟合→源图/拟合/镜像/首尾播放。身体和特效分别验。
5. 接源码、角色 provider、动作表、事件与时间线；玩法扩展用独立候选，保留冻结版。改可变模拟状态同步改快照与哈希。
6. 运行适当专项：真实按键、30/60Hz、镜像、打空/格挡/命中、资源不足、取消边界、退出回收。不能直接改状态冒充实打连段。
7. 运行规则、像素、全流程与回滚检查，并查看桌面及手机截图。记录峰值和局限；再请用户评估美术与手感，真机另验。
8. 保存源码、顺序表、拼接包、原图、提示词、标定、拟合、编排、测试及构建哈希；更新一份维护入口，不再向入口无限叠加“最新”。
9. 提交前扫描隐私、密钥、大文件和漏掉的依赖。归档项先列清单、保存原路径和 SHA256，再移到待取走目录，不删除唯一资料。
10. Git 先同步远端、保全分叉历史，再合并。旧工作分支有独有成果时先留档案标签；推送并核对远端后才删除分支，不强推主分支。

## 当前常用验证

在仓库根目录运行，依赖 Python、Pillow、NumPy、lupa 的 Lua 5.3。部分旧工具还依赖 OpenCV、Node 或本地 GIA codec，按其说明安装；不把整个依赖目录提交。

```text
python -X utf8 runtime/tests/run.py
python -X utf8 runtime/tests/mock_flow.py
python -X utf8 runtime/tests/traveler_wind_combo.py --target outputs/tutorial-wind-fx-v27-20261017
python -X utf8 runtime/tests/traveler_juggle_lesson.py --target outputs/tutorial-wind-fx-v27-20261017
python -X utf8 runtime/tests/traveler_wind_replay.py outputs/tutorial-wind-fx-v27-20261017
python -X utf8 runtime/tests/traveler_extended_juggle.py
python -X utf8 runtime/tests/traveler_wind_fx.py
```

教学总回归用 `runtime/tests/teaching_input_suites.py`，参数以脚本为准。若改 `game/`，另按其 AGENTS 运行确定性、联机、触控、两种比例全流程。

## 重建与恢复

普通维护版从 `runtime/source/order.json` 经 `runtime/tools/build.py` 重建。独立教学 v27 从自己的 `source/order.json` 拼接，各项来源与拟合见构建工具。v26/v27 的制作工具引用 v25 及更早逐批源码和母版标定，因此旧教学源码链保留为历史依赖，不能只保留 v27 源图后称可全量再制作。

归档恢复按 `archive-manifest.json` 的原相对路径回放；已归档的旧验证可从待取走目录查阅，重跑测试会产生新证据。生成过程与验证环境可能随依赖版本变化；最终交付以保存的构建哈希为身份。

精确重建注意换行：v27 生成时 Windows 文本写入产物为 CRLF。各 source 读作文本后以一个 LF 分隔，再统一写为 CRLF，可逐字节得到保存的 SHA256；直接拼原始文件或在其他系统默认写 LF 会产生不同字节哈希。Git 对候选源码与产物禁用自动换行转换，保留原始文件。

本次验证环境锁定到根目录 requirements-maintenance.txt：Python 3.11.4、lupa 2.8（明确使用 lupa.lua53）、NumPy 2.4.1、Pillow 12.1.0。新环境先安装这些依赖，研究视频处理与 GIA 编解码按各工具说明另外配置。
