# 原神格斗 v2

千星奇域（7.1 客户端 Lua）里的 2D 格斗游戏，在原 1.1 工作区的基础上从头重写。全部代码在 `game/` 目录下，旧目录没有改动。

- AI / 开发者先读：[AGENTS.md](AGENTS.md)（硬约束、架构、测试）和 [docs/UI_STYLE.md](docs/UI_STYLE.md)（界面规范）。
- 交付物：`dist/genshin_fighter.lua`（单文件，由 `tools/bundle.py` 生成）。

## 内容

- **流程**：开场 → 标题 → 主菜单 → 选人 / 选场景 → VS → 对战 → 结算。
- **模式**：街机（6 连战，最后一战是头目）、对战电脑、本地双人、联机对战、训练（陪练动作可选、能量无限）、出招与系统说明、设置。
- **角色**：16 名，分 5 类武器招式；每名角色有专属元素战技和元素爆发，爆发带特写演出。
- **系统**：轻 / 重 / 下段 / 投技 / 冲刺 / 后撤、连段取消、伤害递减、浮空连段、防御分上中下段、元素附着与元素反应（蒸发、融化、超载、冻结、感电、扩散、结晶等）。
- **场景**：七国各一张拟合背景画；前景层会动（草叶摆动、落叶、雪等），有视差和镜头运动。
- **操作**：键盘双人、手柄、手机触屏（浮动摇杆加按键，支持多指）。
