# 格斗原型 v0.2：下段与特殊技

玩家刻晴对 AI 迪卢克。人物依然是程序绘制的玩法示意。

运行根目录 `启动格斗原型.ps1`，打开 http://127.0.0.1:4192/ 。页面标题为 FIGHTER V0.2。

| 输入 | 行为 |
|---|---|
| A / D | 移动 |
| Space | 跳跃 |
| J | 普通中段快剑，站防/蹲防均可挡 |
| 按住 S，再按 J | 下段，站防不能挡；离地超过20的对手避开下段 |
| K | 上段重击，蹲防不能挡 |
| 按住 L | 站防，挡中段与上段 |
| 按住 S+L | 蹲防，挡中段与下段 |
| E | 刻晴突进斩：伤害16，冷却3模拟秒 |
| R | 重开 |

迪卢克 AI 会使用下段、上段、火焰重斩，以及蹲防回应下段。火焰重斩为中段：27步前摇、范围240、伤害22、冷却5模拟秒，站防/蹲防均可挡。这是本原型设计的长距离火焰斩，不是完整复现原作技能或投射物。

触控：按住 CROUCH 后点 ATTACK 为下段；CROUCH+GUARD 为蹲防；SPECIAL 使用特殊技。当前触控多指行为未真机核验。

特殊技地面施放、无无敌帧；冷却从施放开始，命中停顿和回合停顿期间冷却随战斗时间暂停。每招一次命中。刻晴突进受边界与角色推挤限制。特殊技当前是快捷键 E，未做方向搓招或招式取消。

原有100血、60秒回合、先赢2回合、跳跃、AI、重开保留。规则内部固定1/60步长，不能代表真机帧率。

已验证22项模拟器检查，新增覆盖上下段防御互克、离地避下段、突进伤害、单次判伤、特殊技冷却、火焰斩前摇/范围和重开清零。详见 verification.json；GIA 已导出并实际重新导入模拟器。真机尚未验证。
