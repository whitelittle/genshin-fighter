# 角色美术制作标准：重点步骤

原图制图标准保持不变。所有新角色和新动作在图片转成标清图元后，必须执行并验收以下重点步骤，不能只验收大尺寸原图。

1. 拟合完成后添加一像素深色轮廓。轮廓色与角色配色协调，避免粗黑边；雷神使用紫黑色，草神使用深绿色。
2. 在拟合后的调色板中加强中间色和阴影的区分，保留肤色、白发与其他亮部。当前仅草神采用内部颜色加深；雷神保留已认可的内部调色板。
3. 原图、初始拟合、优化拟合按同一角色显示高度并排比较。必须检查脸、头发、衣服、大轮廓，以及深浅背景下的可读性。
4. 关键帧和补帧使用同一轮廓规则与调色板，检查播放时的轮廓闪烁和配色跳变。
5. 比较单帧最大和全套平均图元数量。当前描边增加图元；内部颜色加深不增加图元。不能宣称未实测的真机性能收益。
6. 保留脚底锚点、显示倍率、动作顺序、打击帧与投技逻辑。美术改动不能顺带改变战斗判定。

当前正式版：雷神一像素紫黑轮廓；草神一像素深绿轮廓和内部色块加深；头像保留原适配。不使用两像素厚边，不恢复高清包。

分层图元、遮罩与覆盖还原角色作为后续研究方向，先验证单个姿势与实际客户端接口。本版不以该未验证方案替换角色。
