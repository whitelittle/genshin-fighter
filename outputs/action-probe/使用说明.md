# 动作设计探针

本轮主要交付：本地动作与特效研究工具。打开 [动作探针](http://127.0.0.1:4196/outputs/action-probe/index.html)。如果本地服务已关闭，在本目录右键运行 `启动探针.ps1`，随后浏览器打开该地址。页面也可直接打开 index.html；本地原片引用可能需 HTTP 服务。

默认显示本轮研究的14位；取消勾选可查看45位现有像素素材。点击角色→普攻/特殊技/必杀→拖时间条或逐帧。迪卢克特殊技可选第一、第二、第三段。改变对手距离与站立、防守、跳跃模式，看红色攻击框是否接触蓝色受击框；金虚线为候选特效外缘。

“新动作结构示意”用简化人物检查剑路、重心、射程与效果，不是角色成品动画。“现有像素姿势”查看已有素材，自动切换或手动选姿势；标记“代用”的状态仍复用旧图。

右侧可改起手、有效、收招、伤害及范围；仅保存在当前页面会话。切换角色可保留本会话修改；刷新恢复候选。“导出当前设计 JSON”保存选中动作，“保存探针截图”保存舞台。导入自己的截图仅在本地显示，不发送服务器。

如果内置浏览器没有出现下载，页面底部会展开完整 JSON，可复制保存；浏览器已核验修改射程后导出的内容同步更新。浏览器自动化未捕获下载事件，因此不把该事件当成已经验证的下载落盘。

展开“原作视频与实机截图参考”可查看9位官方原片的抽帧，点击图片放大。其余5位研究仍缺本轮目视抽帧，见设计文档。参考录像与图片是研究资料，不打进游戏 GIA。

AI 模式仅演示公开起手后18帧防守；没有完整对战 AI。伤害是静止假人接触窗口的示意，未模拟击退、硬直、墙边、资源或回滚。新招式、效果和数值未覆盖正式战斗。

本地模型10项检查通过；浏览器抽样与游戏菜单的模拟器布局检查另见报告。没有声称官方千星导入、手机性能或平衡已验收。

设计与参考说明：[动作探针与本轮研究](../../docs/动作探针与本轮研究.md)。构建入口 `work/build-action-probe.mjs`；动作候选 `work/action-probe-design.mjs`；界面源码 `work/action-probe`；检查 `work/verify-action-probe.mjs`。未删除旧文件。


## 2026-10-03 参考后优化版

刷新原地址即可查看，无需重装 GIA。本次仅更新动作探针，正式战斗、联机协议和旧导出包未更改。

- 增加待机、行走、蹲伏、站防/蹲防、受击、浮空、倒地、起身、跳跃入口。现有像素帧可查看；缺失或重复代用帧回退为明确标注的结构示意，不冒充新像素动画。待机轻微呼吸位移也是代用。
- 刻晴的新动作结构具有下沉、收手、挥剑、收招，刀光使用同一剑尖轨迹。E 有雷楔和瞬移尾迹，Q 有剑路与残影示意；仍需重画完整像素帧。
- 那维莱特喷水增加聚水、开束、流动细线、接触水花；超出范围空放不显示接触闪光。其他候选获得分层形状研究，可用效果版本比较原始示意。
- 半屏立绘仅在刻晴/迪卢克 Q 起始短时展示，可关闭；它不是新施放动画。状态型必杀的配套动作仍待定。
- 放大舞台方便检查细节；“新动作结构示意”看动作实验，“现有像素姿势”看已有角色素材。

验证：模型原有10项检查通过；42个招式、两档效果、六个时间点共504次原生Canvas绘制检查通过。浏览器抽查刻晴普攻与基础姿势、那维莱特喷水命中/反向空放，无错误日志。手机简化档仅减少绘制细节，未做真机帧率或GIA图元成本验收。参考来源与影片时间点见 `docs/格斗动作与特效观察记录.md`。
