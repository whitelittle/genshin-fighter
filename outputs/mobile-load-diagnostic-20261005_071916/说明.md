# 手机战斗加载诊断 D3停用菜单

基于050817封面选人恢复版，进入战斗加载时对HomeScreen与SelectScreen调用SetActive(false)，返回菜单加载时恢复；用于验证停用隐藏菜单能否消除手机端实例化卡顿。加载顺序、批量与控件数量不变。

双方确认后进度条下方显示：

D3 阶段 | decode 已解码 left 剩余 | create 已创建/应创建 | task 已完成/总任务 | dt 帧间隔毫秒

阶段依次为 DECODE → CREATE → READY。请录屏，记录CREATE阶段的创建速度、dt与最后数字。

替换双方A为本版，沿用B、GF10与变量，核对B外层索引。
