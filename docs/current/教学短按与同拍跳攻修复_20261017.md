# 教学短按与同拍跳攻修复

2026-10-17。匿名玩家澄清：下段攻击本身没有问题，指下段教程和自由练习里跳打按键失效。本批保留下段攻击规则和全部美术。

模拟器复现：v23下段教程内，触控跳按钮在相邻两次模拟采样之间按下并松开，下一拍没有进入起跳；随后轻按钮相同快点也没有攻击。键盘／触控均按最终保持状态采样，旧触控只有E/Q额外在click记录脉冲，跳／轻／重没有。另在四种课程课后菜单进入自由练习，跳与轻／重同拍输入会先出地面轻／重，而非空攻；晚五拍输入可用。此前测试在按下和松开之间推进一拍，未覆盖短按；v22只补蹬地四拍，不覆盖同拍起跳之前。

修复设计与实现：独立v24在输入层记录键盘／手柄绑定的按下位和触控按钮的按下位，下一次输入采样消费一次，保持状态继续保留。触控E/Q同样改在down记录，去除click再次记录，避免松键重复出招。短按方向也能在该次采样参与组合键。旅行者教学模拟器遇到新按跳跃与轻／重同拍时进入蹬地，将对应攻击交给v22已有缓存，离地执行；同时轻重以重击优先，显式战技／大招／投／冲刺优先级保留。仅改输入接收与此项起跳选择，其他角色共享模拟源码不变。

只修改三份源码：`source/input/gf_input.lua`、`source/input/gf_touch.lua`、`source/teaching/gf_sim_lumine_training.lua`。所有其他源码、身体数据、渲染、派蒙、下段招式参数与课程判定逐字节保持v23。独立包`outputs/tutorial-short-press-v24-20261017/`，构建SHA256：`d3b0304d4c101fb59aeb581971e23772a37b2c9e70e732d0bfde6443a21a4dd0`。
