# V9 用户反馈与待定设计分流

2026-10-14。用户最新工作原则：用户反馈与待定设计分别记录，两者逐步推进；严重体验问题优先处理。不能以新玩法开发替代现有问题修复，也不能把讨论中的设计当作已决定参数。

## 用户反馈轨道

正式反馈清单：[匿名玩家反馈汇总](V9_匿名玩家反馈汇总_20261014.md)。每项记录“现象→证据/复现→原因或待验证推断→修复版本→离线检查→真机/用户验收”，不把现象与解决建议混写为同一事实。

优先处理顺序：

1. 无法开始或无法继续游戏：移动开始页至少两例反馈，受影响设备仍未验收，问题未关闭。
2. 严重掉帧、卡死、同步或伤害错误：PC连续攻击十多帧、视觉接触无伤害等。性能候选和枪弹修复的离线结果不等于真机关闭。
3. 比例、说明、视觉可读性及内容丰富度：按实际影响排队；若造成无法辨认招式或误判战斗结果，可提升优先级。原有台账的优先级不因此自动降低。

近期反馈保持为独立问题：动作偏少；出招不明显；三段J看起来一样；克洛琳德射击视觉命中无伤害；部分身体母图剑刃过短。三段J的现行命中衔接条件已经查明，但允许空挥连三段属于解决方案候选，不标为已经批准或修复。
