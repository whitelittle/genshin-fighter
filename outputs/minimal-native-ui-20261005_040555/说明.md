# 最小界面排错

仅两个客户端控件：FighterDemo容器与预置诊断文字；沿用上一排错包同样短脚本，不含高清场景、头像或控件池，也不使用B。原素材和全部正式候选保留。

导入后必须让当前默认布局实际显示这个新A给试玩玩家，仅进入资源库不等于显示。编辑时应有FighterDemo与NativeBootProbe名称，右侧可编辑属性，画布有UI MOUNTED / LUA WAIT。试玩时预期LUA UPDATE OK和递增数字。若编辑器有文字但试玩没有，先查当前布局显示绑定；若最小包编辑器也缺名称和属性，应核对原生导入结构。

模拟器：实际导出GIA回读后验证启动更新，真实文字渲染，无PNG替代。真机：未验证，不宣称游戏修复。
