## 报错复现与修复

旧v16在进入自由练习后再次点击原“自由练习”按钮位置，精确复现 `genshin_fighter.lua:12246: attempt to index a nil value (field 'completeMenu')`，与匿名截图一致。

原因：菜单释放只释放绘制图层，点击区域及回调仍存活。再次触发回调访问已置空的completeMenu。

修复：菜单释放时标记freed，注销仍由自身持有的区域回调并隐藏按钮；pick拒绝再次处理已释放菜单。自由练习分支先取局部菜单并清空引用，再释放菜单、清UI输入区域并重建当前操作。主维护源码gf_ui与gf_training_lesson同步修正。不是只加空值判断掩盖旧点击区域泄漏。
