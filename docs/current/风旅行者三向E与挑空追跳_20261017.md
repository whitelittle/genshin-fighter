# 风旅行者三向E与挑空追跳

2026-10-17。用户明确“试试水”是先试做风旅行者，不是水旅行者。设计由用户给出：普通E向前搓风球，上E腾空后丢出风球，下E释放风刃，都有身体动作与独立特效。后续要求挑空和追跳进入教程，连段应遵循格斗游戏的命中确认、取消与保护框架，并以旅行者作后续角色重做的样板。

## 当前候选与操作

独立v26先接12张身体姿势、程序形态特效和四步挑空教程；没有作为最终美术或正式版交付。用户随后要求特效单独绘制，独立v27使用风球、风刃、命中三组各四帧的独立绘制源图与像素拟合，替换程序圆环。v25防御节奏、v24短按与起跳输入修复保留。

按键：E搓球推出；W＋E腾空投球；S＋E挥出低位风刃。三向E共用150拍冷却。风球是实际移动碰撞体，不再由人物前方瞬间矩形代替；命中、被防、打空与反应仍走已有确定性模拟。

新课程“挑空与追跳”在空中课之后、防御课之前，四个目标为：蹲重挑空并观察落地；命中后向前追跳；追跳接空轻；完整五击路线。按面对右侧时的输入：

`J → 命中后J → 命中后S＋K → 命中后松S、D＋空格 → 空中J命中 → K收尾`

左侧对手改用A为前方向。W也可跳跃；触屏用前上方向或跳按钮配合摇杆；手柄提示采用当前项目布局。每一步需要自己操作，没有自动追踪、吸附或一键连段。课程在收招与落地后再反馈成功；打空、被防、断连不计完成。

## 设计与实现边界

旅行者轻一／轻二可按明确表接后续普攻、蹲重或E；蹲重保留22拍前摇、5拍有效与28拍收招，命中挑空。命中后的取消窗口截至起手＋有效＋8拍，打空／被防不能跳跃取消。跳跃取消保留普通跳跃的24向上速度和5.6水平速度，由玩家选择方向；不使用隐藏追踪。轻二命中已经浮空的目标时也可跳跃取消；轻二打中地面目标不因此变成自动挑空。

空轻可以接空重或E，空轻命中停顿中的输入也能接收；切到E时清掉旧空攻覆盖，避免规则已施法但身体仍显示空轻。空重仍向下收尾。

v27给风E12拍收招、风球18向上速度，允许蹲重命中后取消接E，形成下落接球的延长机会。普通E和上E可浮空，下E仍是低位风刃。冷却不因连段取消重置。

蹲重命中后的冲刺取消为额外的候选延长手段，消耗10能量；打空／被防无效，能量不足给出提示，不触发取消。这会与大招资源竞争，尚待手感和平衡验收。普通完成收招后的冲刺不收取这笔取消费用。

倒地／起身状态继续不可被普通E捞起。本批是尚未落地时的浮空延长，没有增加OTG。浮空次数、伤害衰减及保护继续累计；所有角色共享模拟、保护上限和其他角色招式未改，不能把旅行者的取消表批量套到所有角色。

## 长路线的模拟器证据

电脑键盘、60Hz、旅行者对丘丘王、初始180单位距离，已用实际输入实打：

`J → J → S＋K → E → 等施法结束、U冲刺 → 看准下降高度J → J → S＋K → U（10能量取消）→ 等对手下降J → J → 原地空格追跳 → 空中J → G支援`

该路线实际11连击，其中9次浮空命中，最后触发60拍保护；之后空重没有继续造成伤害。证据`outputs/tutorial-wind-fx-v27-20261017/verification/extended-juggle.json`与`runtime/tests/traveler_extended_juggle.py`。路线需要空支援，不能宣称旅行者无支援也已实打到保护；也不是所有距离、设备和对手均已验证。第五段基础路线主动用空重结束，不要求每条连段都打满保护。
