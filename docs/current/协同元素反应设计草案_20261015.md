# 协同元素反应设计草案

2026-10-15。用户要求思考元素反应。本稿为横版格斗改编建议，未修改规则、素材、联机协议或交付包；数值和范围未锁定。协同位沿用户已确定的第2选/第4选，不再解释为车轮备用位。

## 当前实现与问题

`runtime/source/characters/gf_element_rules.lua`已有10类反应名称和元素配对。现有命中代码以对手自身角色元素及`coat`计时判断反应，不是完整的“被攻击后获得对应元素附着”系统；独立协同候选暂时抑制该旧判定，以免未设计的新协同顺便触发旧反应。不能将表中已有名称视为本稿的新体系已经实现。

## 核心建议

采用“主角色元素命中挂标记→选定协同角色以另一元素命中→反应兑现”，反向顺序同样可以触发。无需新增反应按键，协同键就是组合时机的入口。

- 标记来自实际受到的元素攻击，不根据角色身份自动推定。普通物理枪击/剑击不默认附着；E、Q、明确附魔招式与协同元素招式负责附着。
- 同元素只刷新有限持续时间，不叠加多层；无反应的异元素配对采用替换标记的小方案。草+冰等不能硬凑一类新伤害。
- 命中才附着；格挡、无敌、落空不挂标记、不触发反应。反应不绕过防御，不为协同额外授予本体取消权限。
- 首版每个目标只保留一个短时附着标记；反应消费标记，设置反应保护间隔，避免多段攻击每段都触发。之后若做草核三元素链，再另扩状态。
- 每种反应突出一种收益：伤害、延迟压力、击退、短控制或防护，不同时附所有收益。多段Q只对实际触发段结算反应，不乘整段总伤害。
- 回合重开、被击败换人时清理目标附着、延迟反应和草核；联机按确定性逻辑拍记录，效果只随确认结果显示。

## 反应的项目改编方向

下表是设计候选，不是原作数值或正式技能说明。

|配对与名称|拟议收益|反制和限制|
|---|---|---|
|雷+草：激化|增强这次确认命中的雷/草攻击，简短追加伤害；不新增长硬控|消费附着、受保护间隔限制；首版不同时赠愿力和强化草种|
|雷+水：感电|短延迟后一次较轻追击，提供有限节奏压力|追击可防御/避开，固定触发区域，不贴身无限追踪或无限硬直|
|火+雷：超载|一次爆炸与明显推开，适合脱困、拉开距离|不叠加高伤与大浮空；推远可能让己方难追击，角落不自动改成弹墙无限连|
|水+冰：冻结|一次短定身，制造确认机会|攻击打碎并结束冻结；同连段只能控制一次，之后给予冻结保护间隔|
|水+火：蒸发|提高这次有效命中的伤害|不额外加大硬直，不放大整套多段Q；比例与上限另测|
|冰+火：融化|提高这次有效命中的伤害，适合重击兑现|与蒸发共享易懂的结算规则，不为了区别硬塞额外控制|
|草+水：绽放|生成一个可见草核，延迟在有限区域爆开，建立站位选择|每方最多一个，有限寿命，不自动追人；先不加入超绽放/烈绽放三元素链|
|雷+冰：超导|一次短时强化破防能力或提高后续物理命中收益，二选一|持续时间短，不能直接删除对手防御，也不长期降低所有防御数值|
|草+火：燃烧|有限次数的小额持续伤害|不叠加刷新成永久伤害、不每跳制造硬直；持续伤害是否可KO另定|
|风+其他元素：扩散|把已有附着变成一个短时可规避的小范围威胁|不再扩散自身产生的扩散，禁止递归触发；风角色尚未因此加入制作范围|
|岩+其他元素：结晶|一次有限耐久的小防护奖励|不等同无敌，不无限叠盾；岩角色尚未因此正式接入|

## 雷神与纳西妲的首批搭配

1. 雷神主角+纳西妲协同：雷神E后的指定雷攻击挂雷；呼叫纳西妲草束命中后激化，加强本次草击。普通薙刀试探仍有物理用途。
2. 纳西妲主角+雷神协同：草芽/取景等指定草攻击挂草；呼叫雷神落雷，兑现一次激化。纳西妲负责铺设和确认，雷神协同提供短时攻击机会。
3. 雷神主角+水协同：水攻击与雷攻击组合产生感电，提供较轻的延迟压力。
4. 雷神主角+火协同：超载推开对手，偏向脱困和控制距离，不能保证更好近身连段。

这使协同选择影响打法，而不只是召来另一种颜色的同等伤害。首批优先做激化、感电、超载三种；冻结、绽放及其他反应保持完整设计清单，逐项试验。

## 表现与负载边界

- 附着用小元素标记或血条旁图标，类型/期限变化时更新，避免身体持续闪光。
- 反应使用短促、可辨认的现有独立层，区别于普通命中；不能落空也出现对手冲击。
- 首版激化和超载不创建长期实体；感电只保留每方一个待触发记录，未来草核每方一个。保护间隔、附着和待触发数据进入快照及哈希。
- 协同本体已经增加同屏可见角色，反应不能再默认复制多个人体残影或铺全屏持续粒子。池容量、可见图元和实际换帧写入分别测量。
- 实施时先修附着来源和消费规则，再加入新收益；不能仅开放旧`coat`判定就宣称新体系完成。离线与真机测量分开，不承诺反应没有额外成本。
