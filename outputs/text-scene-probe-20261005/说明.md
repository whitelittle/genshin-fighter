# 文字场景独立探针

设计：将16色场景按颜色拆为16个文字控件，以实心方块和空白字符排列。保留原始素材和210009。没有持续换帧或Lua更新。

程序：网格224×126；场景16个文本层，附标题及对齐检查。空白组合依赖字体度量，平台字体变化可能错位。文字总长度、GIA大小、整层文字纹理估算见report.json。

模拟器：结构检查通过、无Lua错误；host-preview.png为离屏渲染。浏览器实际效果另行确认。整层文字纹理可能较大，控件减少不能直接推断省电。

真机：未验证。字数限制、字体、排版、手机发热与耗电、动态换帧成本仍待测。

浏览器模拟器观察：已打开试玩页面，文字场景可见，但出现横向错层。browser-preview.png记录实际页面；不能用离屏预览冒充浏览器已正确还原。字体度量及自动换行是待验证原因。整层纹理RGBA面积估算约212 MiB，不含额外开销，不代表实测内存。
