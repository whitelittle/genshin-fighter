# 动画素材生产与验收流程

用途：可分享的通用制作方法，不包含项目角色、会话或个人路径，不要求接收项目修改全局规则。

## 输入规格

先确定镜头、朝向、角色显示尺度、脚底基准、服饰母版和持械方式。每个动作写出意图、起手、有效、收招及连接状态；图片帧数与逻辑帧数独立。参考图分别标明身份、画风、姿态或轨迹用途，避免将正面展示图误用为侧向动作帧。

## 制作与复核

1. 先生成或绘制无特效关键姿势，检查支撑、握持、轮廓和镜头一致性。
2. 四格姿势板仅用于设计比较。运行时帧宜逐姿势输出；不要默认等宽切片，长武器可能跨格。
3. 关键姿势通过后补连接帧，明确每张连接的起止姿势与轨迹。快速动作允许跨幅，不把均匀插值当作质量标准。
4. 特效独立分层，并绑定角色/武器/地面锚点。空放、防御和命中使用不同反馈。视觉面积不等于碰撞范围。
5. 检查实际alpha而非只看预览底色。背景光晕、半透明整图、裁切和人物跨格均应阻止自动接入。
6. 在实际显示尺度进行像素网格、有效色、保护修边与矩形拟合，保留原图与版本。
7. 检查慢放、循环接缝、镜像、脚底漂移和状态连接。模型、浏览器、平台真机验证分别记录。

## 输出与负载

交付母版、逐帧图片、帧序/持续时间、锚点、事件及来源记录。矩形数据总量、每帧数量、共享池峰值、容器与图片控件、可见/常驻、属性更新及重叠面积分别计量。隐藏、回收池、销毁不是同一操作。补显示帧不应隐式改变判定事件的逻辑时刻。

未通过的候选与缺陷应保留并标明，不能用“已生成”替代“可运行”。没有同设备对照测量，不宣称性能验收通过。
