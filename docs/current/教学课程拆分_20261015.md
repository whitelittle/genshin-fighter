# 教学课程拆分

> 最新用户决定：七元素都纳入教学；投与拆投合为一课；先做出关卡再慢慢微调。v3独立候选已加入10类课程选择及7元素子目录，当前可练基础移动5目标和普通攻击中的轻击入门2目标。课内自动对话，课末重练/选课/自由练习，中途暂停可返回课程；键盘/触屏/手柄分别提示。其余课程明确待接入，未以目录展示冒充可玩。8816已更新为课程入口，原v1/v2包保留。

2026-10-15。最新用户要求按设备说明操作，并补防御、重击、空中/蹲下攻击、多个E、大招、支援及元素反应；随后明确建议分开。以下拆分优先于此前全部连续教学的扩展建议。

## 结构

采用独立课程选择。课内保持“顶部目标→派蒙说明→实际完成→回应与下一句”；一课完成后给出重练、回课程选择及进入推荐下一课的明确选项，不无条件自动启动其他大类。每课单独从准备状态开始，设置对应陪练行为，不继承上一课的伤害、命中计数、冷却或附着导致跳步。

|课程|练习内容|本批状态|
|---|---|---|
|基础移动|前走、后退、跳起落地、前冲与后撤|前四项已有六步候选中的验证；独立课程入口及后撤目标待接|
|普通攻击|轻击、三段连接、重击及打空收招|已有一次轻击；三段/重击动作与规则待接|
|下段攻击|蹲轻、蹲重，命中高度与恢复|待制作接入|
|空中攻击|跳跃后空轻、空重及落地|待制作接入|
|防御与反击|站防、蹲防、守错高度、对手打空后反击|防御素材候选已有；陪练攻击和目标检测待接|
|元素战技|普通E、上E、下E各自一个独立练习，再解释共享冷却|荧战技尚未设计接入，不沿用其他角色规则冒充完成|
|元素爆发|积累能量、释放、命中/落空/被防分支|待设计接入|
|支援|选择的协同位、呼叫、真实协击与冷却|已有独立协同原型，未接荧教学候选|
|元素反应|先学一种反应：附着→另一元素命中→反应；与支援课分开|当前仅设计草案；实际附着规则与荧元素方案待锁定|

按用户此前要求逐组打磨，先完成当前基础，再依序扩展；不因此自动批量生成全部新动作。不增加尚未定案的投技/拆投必修课。

## 设备提示

每课按实际输入设备动态显示。键盘沿现有绑定：J轻、K重、E战技、Q爆发、U冲、W/空格跳；手机用相应按钮名称与摇杆方向；手柄用已绑定的平台功能名，如普攻键、交互键、技能1、技能2、冲刺键、跳跃键，不猜测具体ABXY/符号。重攻击当前绑定交互键的事实要如实提示，后续统一键位时同步更新。

后方向始终相对对手解释，不能把A永远写为防御。支援当前独立原型有键盘G/触屏协同及手柄组合输入，但尚未进入教学版，不把未接入按键显示为可用。
