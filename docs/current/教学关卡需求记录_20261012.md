# 教学关卡需求记录

## 用户明确需求

2026-10-12，来源：匿名玩家。当前为后续需求讨论与记录，沿用“先别制作，先聊会”的范围；未制作素材、未开发关卡、未修改或发布程序。

- 增加教学关卡，教玩家按键操作。
- 制作派蒙头像，用于教学引导。用户口述“派梦”，此处按角色派蒙记录。
- 制作派蒙小像素人。
- 制作一整套旅行者角色素材与动作，不能用少数教学展示姿势替代完整角色。
- 制作丘丘人木桩，包含被击、被投动作，供教学练习。

## 设计建议，尚未实现／验收

派蒙头像用于提示框，小像素人用于场景引导；具体表情、动作数量、大小、摆放和是否需要语音尚未确定。

旅行者完整动作沿现有角色规范梳理：待机、移动、跳跃、蹲下、防御、轻重攻击、E／Q、投技／被投、受击、倒地／起身及胜负等。具体招式设计、男女旅行者选择、元素版本和是否需要多元素套装尚未确定，不自行推定全部制作。

丘丘人木桩作为练习目标，至少支持受击和被投的完整反馈；站立、受击恢复、被投落地／复位的衔接需要配套。木桩是否移动、防御、反击或存在不同受击高度待设计，不从木桩需求推定完整敌人AI或完整可选角色。

教学可依次覆盖移动、跳跃、轻／重攻击、防御、E、Q、投技等。具体顺序待确定。提示应对应当前设备的实际操作：键鼠按键与手机触屏按钮分别显示；不能只写键盘字母而让手机玩家无法操作。

步骤完成建议依赖实际输入和模拟事件，区分“按下了键”“招式成功发动”“命中了木桩”，不能只播放动画就判定学会。E／Q需要安排冷却和能量，投技需要说明距离及地面条件；失败后可重复练习。已教动作可自由复习，跳过／重试／返回入口待设计。

## 结构与素材边界

教学步骤和关卡流程放在独立模式／场景，调用现有输入与战斗规则；不复制第二套伤害判定。派蒙提示使用既有gf_ui组件，旅行者和木桩素材沿角色／目标数据访问边界接入，便于作为独立教学模式组合。

共享只适用于完全一致的只读图片载荷、调色板和元数据；派蒙、旅行者、木桩各自的动作与运行状态独立。后续须把新增素材计入65角色计划及奇域容量预算，教学素材不视为免费容量。当前紧凑／压缩实验不代表这些新素材已制作或已满足容量。

## 待定项与状态

旅行者性别和元素、派蒙表情与动作、木桩外观与动作数量、教学顺序和入口、教学进度保存、是否必须完成及语音均待讨论。此清单不表示立即开发授权，也不代表设计、模拟器或真机验收。
