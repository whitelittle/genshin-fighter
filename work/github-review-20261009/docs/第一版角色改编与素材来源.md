参考 [DNF Duel 官方系统说明](https://dd.nexon.com/en/system/total) 中的基础攻击、方向配合技能与从简单连招起步。我们的决定是直接 E/Q，S+K 升空，搓招保留为可选输入；没有照搬其 MP、白血和觉醒系统。

官方角色参考入口：[凯亚 HoYoWiki](https://wiki.hoyolab.com/pc/genshin/entry/9?lang=en-us)、[烟绯 HoYoWiki](https://wiki.hoyolab.com/pc/genshin/entry/24?lang=en-us)、[胡桃 HoYoWiki](https://wiki.hoyolab.com/pc/genshin/entry/34/?crawler=Googlebot&lang=)。官方演示：[甘雨拾枝杂谈](https://www.youtube.com/watch?v=tsPtGG9pFfg)、[魈拾枝杂谈](https://www.youtube.com/watch?v=kCmvCpYL34U)、[可莉拾枝杂谈](https://www.youtube.com/watch?v=jdq2shrprdU)。部分动态网页无法提取完整正文，不能称作本轮已逐帧审看所有官方视频。

## 素材与动作状态

九个新姿势表用内置 imagegen 生成；透明源图保存在 `assets/test-v1/*-sheet.png`，没有替换旧素材。统一提示要求 4列×3行、面向右、全身、同尺度、待机/两步移动/蹲伏/站防/蹲防/受击/倒地/跳跃/平A/E/Q。角色描述加入各自服装、武器与元素。完整提示与来源路径见 `assets/test-v1/source-manifest.json`。

拟合：18色、84像素站立基准，可莉66、岩盔丘丘王104；保留透明区域。12个独立关键姿势，另外8个状态名称复用关键姿势。新角色 **不是20幅独立细致动画**。待机有轻微上下移动，两步行走，E/Q 各有动作姿势；大量中间帧、独立胜利动画与入场演出尚未验收。

菜单预览使用小图元池；战斗源保留更细网格。角色图片使用逐姿势调色板与坐标紧凑字符串，重复姿势引用同一表，战斗前分批展开两名所选角色。退出后释放展开表；保留紧凑源数据用于下次进入。

**模拟器验证**：11角色动作入口、新特性中的魈充能/跳跃、胡桃耗血/回血、琴挑飞、甘雨退步、烟绯丹火印、岩盔保护已检查。新字段跟随 fighter 快照复制。真机渲染、身体注册点稳定度、操作手感与平衡仍待实测。
