# V4 角色创建说明

## 当前范围与基线

V3 E 版保留为已认可运行基线。V4 制作原阵容隐藏的14人：芙宁娜、钟离、玛薇卡、温迪、神里绫华、达达利亚、荒泷一斗、八重神子、阿蕾奇诺、流浪者、那维莱特、克洛琳德、娜维娅、丝柯克。刻晴、迪卢克不在本轮范围。批量制作候选，不要求等前一人全部验收才开始下一人。

## 先分析角色，再设计招式

每人记录性格、世界观中的能力、招牌道具/伙伴、原作动作依据、格斗定位与弱点。参考优先官方演示和可逐帧查看的实机录像，逐条保存网址、时间点、观察与改编理由。没有核实的设想只标设计候选，不能当作原作事实。

武器按招式需要出现；站立帧不强制持武器。角色特色应体现在普通攻击、移动、E、Q、投技，不能只换颜色或复制通用剑招。芙宁娜围绕空手指挥、海薇玛夫人、乌瑟勋爵、谢贝蕾妲小姐协作；抱海马喷水是候选普攻，三小只协同喷水是候选E，舞台多段演出是候选Q。具体帧数和数值仍需迭代。

## 每招的动作卡

记录actionId、60Hz逻辑帧的起手/有效/收招、伤害、硬直、击退、取消、移动、无敌/可抓条件、受击盒、攻击盒、独立命中ID、帧序列、锚点、特效事件和双方并发预算。视觉图像不自动决定判定。快速位移采用连续扫掠；多段明确伤害次数。

E必须有明确起手、作用过程、收招和反制窗口。Q命中确认才进入完整演出；落空、防御要有独立处理，不得锁住未命中的对手。投技包含抓取、双方锁位、投出、被投、落地、起身及逃脱/不可抓规则；不能只制作施术者。

## 动作覆盖与提示词

按V3统一标准覆盖待机、六相位步态/后退、冲刺、蹲下、防御、跳跃五阶段、轻攻三段、重攻、蹲轻/蹲重、空轻/空重、E、Q、投技、被投、受击/倒地/起身、胜败等约25组。组数不是帧数；轻重攻击至少准备、出手、有效、恢复四个可读姿势。

每组提示词包含母版身份、专属逐格动作、固定比例/朝向/脚底基准、握持关系、分层要求和禁止项。不得仅替换角色名。禁止把步态补帧混入待机，禁止自动裁切居中掩盖脚底漂移。

## 画风、分层与拟合

已认可雷电/纳西妲为画风约束，保持修长战斗比例、清楚色块、受控高光；不转大头短腿Q版。身体、助手、武器/道具、飞行物、命中效果、舞台背景分别管理。固体握持道具可以出现在动作构图里，但正式接入须确定是否拆层；水柱和粒子不烘焙进身体图。

用既有premultiplied-alpha BOX、重要像素加权OKLab和共享调色板工具进行标清拟合。拟合后加协调的一像素深色轮廓；雷电保留认可内部配色，纳西妲保留内部色块加深。逐帧检查脸、手、衣服、武器、脚底、轮廓闪烁和深浅背景可读性，记录平均/最高图元数、源图/导出哈希。先标清播放检查，再模拟器和真机；不得从图元数量推导未经实测的性能提升。

## 制作与验收状态

设计候选、源图生成、切帧、锚点复核、标清拟合、播放检查、逻辑接入、模拟器验证、真机反馈、用户验收分别记录。批量生成不等于角色可玩。未验收资产不得加入正式选人页。错误保留并记录，优先持续推进全队候选。
