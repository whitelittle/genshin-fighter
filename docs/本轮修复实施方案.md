# 本轮修复实施方案

2026-10-04，依据用户批准的加载与碰撞方案实施。保留旧包和素材，不删除文件；模拟器验证与真机测量分别记录。

## 实施顺序

1. 加载调度：跨界面黑屏真实读条；同页状态同步不重复加载。按父容器复用图元池，减少同场换人、切页时的销毁重建；离开比赛释放战斗池。只保留当前页面、当前两人及至多两位已锁定首发的解码数据，避免全角色常驻。
2. 锁定后的后台准备：在选人页继续运行握手和界面，利用等待另一方准备的时间解码已锁定首发角色。取消锁定时取消相应队列。进入战斗前仍必须完成全部所需资源，不能让未加载动作漏判定。
3. 碰撞：体型分类配置身体推挤框、状态受击框、招式攻击框；镜像和有效帧由确定性模拟控制。有伤害的投射物/特效使用独立框，装饰特效无框。开放数据和框预览供人工校准，不把统一增加距离当修复。
4. 战斗阵容栏：当前高亮、待出战正常、败北灰色、胜利标记，保持固定三场两胜。回合记录进入快照，平局/提前两胜/重新选人清理单独验证。
5. 美术专项：真实交替步态先做一位样板；绫华比例做统一画风对照。逻辑阶段不宣称上述素材已修复，不用缩放或平移代替返修。
