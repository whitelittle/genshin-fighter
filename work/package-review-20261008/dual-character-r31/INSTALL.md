# 雷电将军与纳西妲 r31 安装与测试

当前正式可选角色仅雷电将军、纳西妲；后续完成一位再加入一位。默认从开场与标题进入菜单，保留单人街机、对战电脑、训练、联机、选人选场、VS、战斗、结果、再来与重新选人完整流程；网站双 AI 仅为独立演示入口。

## 文件组织与 require 探针

模拟器真实 Lua Worker 已验证独立脚本文件的 require、嵌套依赖、重复读取缓存及表共享。主文件只保留逻辑；gf_art_sd.lua 保存原标清美术与公共素材，gf_art_hd.lua 保存高清角色动作素材。引入路径固定为 default_import_file/gf_art_sd.lua 和 default_import_file/gf_art_hd.lua，不要重命名导入映射。require 依赖为单向结构，不使用循环引用。

本结果只证明模拟器行为；官方客户端多文件加载与导入仍需真机核对。本包另附 genshin_fighter_standalone.lua，逻辑和素材内容相同，供不使用多文件模块的旧工程替换。

## 已安装双池工程

推荐模块版：先导入 GF_ART_SD_HD.gia，它只注册两份素材脚本，不要把素材脚本挂载到控件。随后将原主脚本全部替换为 genshin_fighter_dual_pool.lua。已有同名素材映射时更新其源码，不要重复导入为不同名字。保留原 A/B、图片模板索引、GF_HOST 挂载、输入监听与 GFV2 服务端节点。

本次首次拆分需要新增素材映射，不能只换模块版主 Lua。若希望仅替换一个 Lua，请改用 genshin_fighter_standalone.lua，保持原挂载，不导入素材 GIA。不要把兼容版与模块版同时挂载。素材包齐备后，后续纯逻辑更新才可只替换主 Lua。

## 全新安装

导入 GF_DUAL_POOL_B_ImageTemplate.gia 图片模板、GF_ART_SD_HD.gia 素材映射，然后导入 GF_DUAL_POOL_A.gia 主界面与主脚本。保留原工程图片模板索引与 GF_HOST 引用；本包不改变 A 控件结构或 B 二进制内容。只有主脚本挂载到 GF_HOST，素材文件通过 require 读取。

GF_DUAL_POOL_Lua_Only.gia 是包含主逻辑和两份素材的可选脚本合集，可代替素材 GIA 加主源码操作。它不携带挂载关系；导入后只将 genshin_fighter_dual_pool 主脚本挂到原 GF_HOST，并移除旧主脚本挂载。避免与 A 中脚本重复导入或重复挂载。

## 联机

沿用归档版 GFV2 服务端转发与回滚联机：同一关卡两位玩家各自在菜单选择对战模式 → 联机对决，分配席位后选人，双方准备，由房主选场并开始。已有 GFV2 节点不要重建。新工程需要按同目录 GFV2_Online_All_Nodes.html 搭建服务端节点；该 HTML 是节点说明，不是可直接导入的服务端 GIA。

浏览器试玩保留联机菜单与等待页面，但本地浏览器模拟器没有官方关卡服务端，不能把两人回滚协议测试当作两个浏览器或两台真机已经联网成功。

## 画质与资源

默认简单画质。电脑在设置里可选高级画质，选择后显示加载百分比，逐帧解码更细的拟合动作，再重新创建设置画面与背景；进入战斗时按所选画质加载角色。高级档两位角色共 324 个动作帧，目标采样高度 160、单帧最多 2200 图元，复杂帧按图元预算缩小。头像沿用原适配，不放大替换。

手机及手机连接手柄固定简单画质，隐藏高画质选项。浏览器设备选择仅模拟设备规则，实际性能需真机确认。

简单画质图元池默认下限 14000，高级画质在画质读条期间预扩容到 24000，动作解码与图元预备全部完成才结束读条。切回简单画质时，在非战斗的画质读条期间清理待释放图元并回收至 14000，达到目标后才返回设置画面；高级档保持 24000 下限；常规大招使用预备余量，动态扩容只处理超出常规预算的情况，上限 32000。余量预警即创建，战斗中不销毁，只在回合结束或对局结束的安全阶段回收。不会降到默认数量以下。

## require 探针复测

require-probe 子目录包含三份微型 Lua 与 GIA。导入后仅挂载 require_probe_main.lua，日志应出现 REQUIRE PROBE PASS；它检查模块 A 的数据、模块 B 调用 A 及缓存共享。此探针不包含游戏，不与正式主脚本同时挂载。

## 本版修复与验证

前景小草取消跨 360 度的旋转补间，改成固定根部的小幅摇摆。雷神大招雷眼按提供的原神截图制作四帧透明特效并拟合为图元，保留已确认的大招节奏。雷神与纳西妲首段命中后的后续段不再被长连击浮空保护吃掉。

纳西妲大招基础配置仍为 250，受每段取整与原连击衰减影响，普通三段实扣 241，长连击后三段可为 72～92；未额外提高基础伤害。防御、护盾和无敌仍可能减少或阻挡伤害。大招伤害数字加大，并保留 1.3 秒；数字显示和实际扣血应一致。

本版使用实际 Lua Worker 与 CPU 画面进行回归，GIA 导出后重新解码核对。尚未完成官方客户端导入、手机浏览器或真机帧率测试，不将模拟器结果当作真机验收。

真机重点检查：两角色选择与重新选人；E/I、Q/O、L 输入；纳西妲三段数字与血条；雷神三刀正常命中与长连击接大；小草不转圈；电脑切换画质读条、手机无高档选项；连续三个回合不叠字、结束后图元回收；返回菜单再进入对局无资源缺失。
