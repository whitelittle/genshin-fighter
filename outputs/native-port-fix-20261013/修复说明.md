2026-10-13，反馈来源：匿名玩家。实际编辑器截图：试玩校验失败，服务器节点图 ID 1073741827；节点 ID 75，关联节点 ID 70。编号属于技术对象标识，不是账号信息。

已确认的导出格式问题：75 是分支，70 是设置 GF3_Locked 的节点图变量节点。设置节点的泛型“变量值”端口直接写了整数／实体值，缺少 ConcreteBase 包装；读取节点图变量则复制了实体自定义变量的类型选择索引。两种节点的映射顺序不同，导致整数／实体选择与声明类型不一致。原逻辑解释器读取数值，未检查此包装与索引，因而漏检。

修正全部同类读／写端口，按原生泛型映射生成包装：设置变量整数索引0、实体索引5；读取变量实体索引0、整数索引2。保留数据查询节点的输出声明。没有改变选人、帧中转、Epoch、防重复退出、结算或Lua代码。
