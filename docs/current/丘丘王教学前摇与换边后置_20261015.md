# 丘丘王教学前摇与换边后置

2026-10-15。用户要求丘丘王有明显前摇；随后明确“防御不教学换边，后面单独教学”。本轮只加强原防御课的举拳/压低蓄力、出手和收招，保持四目标，不增加换边练习。

## 程序与素材接入

上段：先下沉聚力12拍，再举拳蓄力至54拍，54拍显示挥拳并进入有效期。下段：先下沉12拍，压低身体抱拳蓄力至60拍，60拍显示砸地并进入有效期。出手后保留短暂发力姿势，再低身收势、回到站姿。

沿用前一版60Hz模拟数值：上段起手54拍（0.9秒）/有效5拍/收招110拍，下段60拍（1秒）/有效5拍/收招74拍。只改视觉，没有延长或提前伤害窗口。

复用已有 `assets/roster-v2/lawachurl-guard.png`、`crouch.png`、`crouchGuard.png`，追加接入旧 `special.png` 挥拳及 `slash.png` 砸地。不是新绘整套丘丘王动画，当前为旧姿势拼接候选。原六帧身体和色板数据完全保留。

显示层增加可选 `nextAttackPose`，仅本丘丘王provider启用，提前把下一攻击姿势画进隐藏缓冲。修复了仅走路预取导致攻击出手画面晚一帧的问题。仍使用既有双身体缓冲与每次换帧分片预算，不改变其他角色的模拟或绘制分支。

## 换边：当前事实与后续设计分开

当前已存在方向语义和转身：待机/前走/后退/蹲下状态每个模拟拍读取对手X位置，自动朝向对手。空中、攻击、受击及落地恢复保留动作朝向；恢复中立后再检查。A/D始终表示屏幕左/右，前/后随朝向解释；防御根据攻击方所在侧判断。

本轮自然前跳对照：旅行者在左、丘丘王在右，距离180设计单位，按右前跳后松键；最高238.5单位，未越过，最终左右差161.96单位。说明当前跳跃高度、水平距离与身体推挤没有配合好。**不能把已有自动朝向说成自然换边已完成。** 本轮未改共享碰撞或跳跃规则。

后续单独课程采用的设计候选：地面走路/普通冲刺保留身体阻挡；前跳在高度与距离足够时可越过，落地恢复行动后朝向对手；允许换位的投技/穿越技能由各招式显式配置。角色在招式执行中保持原朝向，避免挥拳途中跟踪转身。碰撞缺口修复并验收后，再做独立“站位与换边”课；不插入本次防御课。
